## 교육 철학

### 1. 한국어를 방해물이 아니라 학습 발판으로 사용한다

한국어 사용자는 이미 다음 개념을 알고 있다.

* 화제와 설명
* 주어와 목적어
* 조사
* 존댓말
* 긍정과 부정
* 질문
* 과거와 현재
* 부탁, 허락, 금지, 희망, 가능

따라서 이러한 개념을 일본어 용어로 다시 길게 설명하기보다, 이미 알고 있는 한국어 문장 의도를 일본어 문형과 연결한다.

### 2. 조사가 아니라 완성된 문장 틀을 먼저 학습한다

다음처럼 가르치지 않는다.

* `は`는 은·는이다.
* `が`는 이·가이다.
* `を`는 을·를이다.

대신 다음처럼 가르친다.

* `A는 B입니다 → AはBです`
* `A도 B입니다 → AもBです`
* `사물 A가 있습니다 → Aがあります`
* `사람 A가 있습니다 → Aがいます`
* `A를 주세요 → Aをください`

사용자는 문장의 목적과 함께 패턴을 익혀야 한다.

### 3. 한 문형을 여러 상황에서 재사용한다

예를 들어 `Aはどこですか`를 배웠다면 다음 상황에서 반복한다.

* 화장실은 어디예요?
* 역은 어디예요?
* 계산대는 어디예요?
* 출구는 어디예요?
* 호텔은 어디예요?

문장을 각각 따로 외우는 것이 아니라, 하나의 구조에 단어를 교체하는 방식으로 익힌다.

### 4. 한국어 보조는 점차 제거한다

초기에는 다음을 모두 제공할 수 있다.

* 한국어 의도
* 일본어 문장
* 한글 발음
* 음성
* 핵심 구조 표시

학습이 진행되면 다음 순서로 보조를 줄인다.

1. 한국어와 일본어를 함께 표시
2. 한국어를 가리고 일본어 말하기
3. 한글 발음을 숨기고 일본어 읽기
4. 음성만 듣고 의미 선택
5. 상황만 보고 일본어 말하기

### 5. 문법 지식보다 여행 과업 성공을 우선한다

문법적으로 완벽한 장문보다 짧고 자연스럽게 목적을 달성하는 표현을 우선한다.

예:

* `注文を変更したいのですが`처럼 자연스러운 표현이 필요한 단계와
* `これに変えてください`처럼 초보자가 즉시 사용할 표현을 구분한다.

### 6. 직접 번역과 실제 일본어 표현을 구분한다

한국어 문장을 일본어로 직역할 수 있더라도 일본 현장에서 잘 사용하지 않는 표현일 수 있다.

각 문형에는 다음을 함께 표시한다.

* 기본 구조
* 자연스러운 여행 표현
* 직원이 실제로 사용할 가능성이 높은 표현
* 초보자가 자주 하는 잘못된 직역
* 더 공손한 표현이 필요한 상황

## 핵심 학습 알고리즘

각 문형은 다음 7단계로 학습한다.

### 1단계: 한국어 의도 제시

사용자가 이미 알고 있는 의미를 보여준다.

예:

`A는 B입니다`

### 2단계: 일본어 기본 틀 연결

`AはBです`

문법 용어보다 문장 전체의 의미를 우선한다.

### 3단계: 단어 슬롯 교체

* 이것은 물입니다.
* 이것은 차입니다.
* 이것은 제 가방입니다.
* 여기는 호텔입니다.

동일한 구조 안에서 단어만 변경한다.

### 4단계: 최소 변형

하나의 문형에서 다음 형태로 확장한다.

* 긍정
* 부정
* 질문
* 과거
* 추가 또는 비교

예:

* `これは水です`
* `これは水ではありません`
* `これは水ですか`
* `これも水です`

초급 단계에서는 여행에 실제로 필요한 변형만 제공한다.

### 5단계: 듣기 인식

사용자가 직접 말하는 문장뿐 아니라 직원이 말할 표현도 학습한다.

예:

* `袋は要りますか`
* `温めますか`
* `ここで食べますか`
* `予約していますか`

### 6단계: 상황 적용

문형을 실제 여행 장면에 적용한다.

* 편의점
* 식당
* 호텔
* 전철
* 쇼핑
* 약국

### 7단계: 보조 제거와 회상

마지막에는 한국어 번역이나 한글 발음 없이 다음 중 하나만 제공한다.

* 상황 이미지
* 한국어 의도
* 일본어 음성
* 직원의 질문

사용자가 일본어를 직접 선택하거나 말하게 한다.

## 문형 선택 원칙

문형은 다음 조건을 만족해야 한다.

* 여러 여행 상황에서 반복 사용할 수 있음
* 단어 교체만으로 새로운 문장을 만들 수 있음
* 직원의 질문을 이해하는 데도 도움이 됨
* 초보자가 짧은 시간 안에 말할 수 있음
* 잘못 사용했을 때 큰 오해를 만들 가능성이 낮음
* 일본 현지에서 실제로 자연스럽게 사용됨

## 문형별 콘텐츠 구성

각 문형은 다음 데이터 구조를 가진다.

* 한국어 의도
* 일본어 기본 틀
* 핵심 조사 또는 어미
* 단어가 들어갈 슬롯
* 기본 예문 3개
* 여행 상황 예문 5개
* 직원이 말하는 대응 표현 3개

* 음성
* 한글 발음
* 보조 제거 단계
* 복습 간격

* 사용자가 이 문형을 왜 배우는지 이해하는가?
* 문법 설명이 지나치게 길지 않은가?
* 단어를 바꿔 재사용할 수 있다는 점이 보이는가?
* 한국어와 일본어의 유사성이 명확하게 드러나는가?
* 차이점과 예외를 필요한 만큼만 설명하는가?
* 한글 발음에 지나치게 의존하게 만들지 않는가?
* 말하기와 듣기가 함께 연결되는가?
* 실제 여행 상황으로 전환되는가?
* 하루 뒤에도 구조를 재사용할 수 있는가?

## 검수해야 할 위험

### 잘못된 일대일 대응

`は = 은/는`, `が = 이/가`처럼 고정적으로 가르치지 않는다.

### 한국어식 직역

한국어에서는 자연스럽지만 일본어에서는 사용 빈도가 낮거나 어색한 표현을 그대로 제공하지 않는다.

### 문형 과다 제공

초급 사용자에게 한 번에 여러 조사, 활용, 예외를 보여주지 않는다.

### 활용 암기 부담

동사 그룹과 활용표를 먼저 암기시키지 않는다. 필요한 표현을 문형 단위로 사용한 뒤 공통점을 발견하게 한다.

### 발음 표기 고착

한글 발음은 초기 보조 수단이다. 일정 단계 이후에는 점차 숨길 수 있어야 한다.

### 말하기만 학습

사용자가 말할 표현뿐 아니라 일본 직원이 되묻는 표현도 반드시 학습한다.

## 전문가의 평가 과업

1. 현재 학습 콘텐츠 전체를 문형 단위로 분류한다.
2. 같은 문형인데 별도 문장으로 중복 제작된 콘텐츠를 찾는다.
3. 문형을 재사용할 수 있는 콘텐츠를 묶는다.
4. 한국어와 일본어의 유사성을 활용할 수 있는 지점을 찾는다.
5. 잘못된 직역 또는 과도한 문법 설명을 찾는다.
6. 초보자에게 너무 이르게 등장하는 문형을 찾는다.
7. 사용자가 말하는 문장과 직원이 듣게 하는 문장의 균형을 평가한다.
8. 문형 학습 이후 여행 상황으로 전환되는 흐름을 평가한다.
9. 한글 발음 보조가 제거되는 과정이 있는지 평가한다.
10. 현재 콘텐츠를 핵심 문형 중심 커리큘럼으로 재배치한다.
