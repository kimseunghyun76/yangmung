## 이 앱의 그림 스타일 두 가지 (혼동 주의)

이 프로젝트에는 **완전히 다른 두 가지 화풍**이 공존한다. 새 이미지를 만들 때 반드시 올바른 화풍을 참고해야 한다.

1. **세션 배경(만화풍 실사 일러스트)** — `public/scenes/session-variants/{미션ID}/*.webp`
   실제 미션(C1~C50) 진행 중 배경으로 쓰인다. 사람 캐릭터(손님·점원 등)가 등장하는 세미리얼 애니메 일러스트.
   예시: `public/scenes/session-variants/C1/solo-shop-01.webp` (편의점 손님·점원).
   배경에 작은 강아지·고양이 인형/장식이 이스터에그로 등장하기도 하지만 주인공은 아니다.
2. **마스코트 3D chibi 캐릭터(양·뭉 듀오)** — `public/scenes/quick-practice/*.webp`, `public/vocab/sign-art/generated/*.webp`
   학습 탭 배너, 간판·표지 어휘 카드 등에 쓰인다. 두 마스코트가 항상 함께 등장:
   - **양(Yang)** — 삼색 얼룩 고양이, 여아 코딩(꽃 머리핀·크로스백 등 소품)
   - **뭉(Mung)** — 시바견, 수컷으로 설정된 캐릭터
   둘 다 큰 눈의 귀여운 3D 렌더 chibi 스타일, 일본 현지 배경(역·거리·공사장 등) 위에 서 있음.

**신규 이미지는 반드시 그 이미지가 쓰일 위치와 같은 화풍을 따라야 한다** — 세션 배경 자리에 마스코트를 넣거나, 마스코트 자리에 사람 캐릭터를 넣으면 안 됨.

## 문제 1 — 마스코트 의상: 뭉(수컷 강아지)이 양과 똑같이 여성 코딩된 옷을 입음

`public/vocab/sign-art/generated/` 폴더(113개 파일, 간판·표지 어휘 카드용)를 확인한 결과, **거의 모든 이미지에서 뭉이 양과 완전히 동일한 옷**(꽃무늬 넥커치프/반다나 + 앞치마 스타일 원피스)을 입고 있다.

- 실사 확인: `public/vocab/sign-art/generated/danshi.webp`("남자" 표지판 카드)에서 뭉과 양이 **똑같은 파란 꽃무늬 앞치마 원피스 + 목에 두른 꽃무늬 스카프**를 입고 있음 — 세일러 교복 리본처럼 보여 뭉의 설정(수컷)과 어긋나는 인상을 줌.
- `public/vocab/sign-art/generated/kiken.webp`("위험" 공사장 카드)에서는 하의는 반바지(뭉)/치마(양)로 구분되지만, 목의 꽃무늬 스카프는 여전히 두 캐릭터가 동일함.
- 이 패턴이 폴더 전체(113개)에 반복되는 것으로 보인다(파일명 목록은 `public/vocab/sign-art/generated/` 참고).

**요청 방향**: 뭉에게는 양과 다른, 성별 중립적이거나 남아 코딩된 의상(예: 심플한 티셔츠+멜빵바지, 스카프 대신 손수건을 목이 아닌 목걸이/배지 형태로, 또는 아예 다른 액세서리)을 입혀 두 캐릭터가 시각적으로 뚜렷이 구분되게 한다. 꽃무늬·리본 모티프는 양 전용으로 남기고 뭉은 다른 패턴(체크무늬, 단색, 별 모양 등)으로 교체하는 것을 권장.

**좋은 참고 예시가 이미 있음**: `public/mascots/yangmung-duo-done.webp`(공식 마스코트 레퍼런스)에서는 양이 파란 꽃무늬 스카프+크로스백+머리핀을, 뭉은 완전히 다른 세이지그린 페이즐리 넥커치프+나무 강아지 발바닥 모양 태그를 착용해 두 캐릭터가 잘 구분돼 있다. `sign-art/generated/` 배치 작업은 이 공식 레퍼런스 대신 둘에게 같은 꽃무늬 세트를 재사용한 것으로 보인다 — 새로 만들 이미지는 `sign-art`가 아니라 이 공식 레퍼런스의 의상 구분을 따라가면 된다.

**범위**: 113개 전부를 한 번에 다시 만들 필요는 없다 — 스타일 가이드(캐릭터 시트) 하나를 먼저 확정한 뒤, 우선순위 높은 카드부터(자주 노출되는 것, 또는 이번에 새로 확인된 `danshi.webp`류) 순차 교체를 권장.

## 문제 2 — C51~C54(안전·생활 미션) 세션 배경 삽화 없음

`public/scenes/session-variants/`에는 **C1~C50만** 폴더가 있다(코드의 `SESSION_MANGA_IDS`가 `C1..C50`으로 고정돼 있기 때문 — `src/views/scene.ts`). 이후 추가된 4개 미션은 배경 삽화가 전혀 없다:

| 미션 | 장소(place) | 시나리오 | tier | 비고 |
|---|---|---|---|---|
| C51 | 실내·길거리 | 지진·재난 대응 | 4 | 안전 콘텐츠(항상 접근 가능한 긴급 화면에도 노출) |
| C52 | 병원 | 병원 접수 | 4 | 안전 콘텐츠 |
| C53 | 쇼핑몰·역 | 미아 찾기 | 4 | 안전 콘텐츠(항상 접근 가능한 긴급 화면에도 노출) |
| C54 | 택배 | 택배 재배달 신청 | 4 | 2026-07-26 신규 제작 미션 |

이 중 C51·C53은 `place` 문자열이 `src/views/scene.ts`의 `BY_PLACE` 매핑에도 없어 완전 범용 기본값(旅 아이콘)으로 떨어지는 것까지 확인해, **이번 세션에서 코드만으로 고칠 수 있는 부분(장소별 아이콘·색상)은 이미 추가했다**(`src/views/scene.ts`, `실내·길거리`/`쇼핑몰·역` 항목 추가). 하지만 실제 삽화(사진풍 배경 이미지) 자체는 여전히 없다.

**필요한 작업**: 각 미션당 3컷(`solo-street-03.webp`, `ff-street-03.webp`, `mf-street-03.webp` — 코드의 `mangaBackdropPool()`이 이 3개 그룹 중 이들 미션은 모두 `'street'` 그룹으로 분류하기 때문에 파일명은 고정, 내용은 자유) 총 12장. 구체적으로 담을 장면은 [`c51-c54-scenes.json`](../generated-image-manifests/c51-c54-scenes.json) 참고 — 실제 상황(지진 대피, 병원 접수처, 미아 안내방송, 택배 재배달)에 맞는 내용으로 채우고 "거리" 느낌에 억지로 맞출 필요는 없다(파일명 규칙만 지키면 됨).

**저장 위치**: `public/scenes/session-variants/{C51|C52|C53|C54}/{solo-street-03|ff-street-03|mf-street-03}.webp` — 폴더가 없으니 새로 만들어야 함.

**참고 스타일**: 기존 `public/scenes/session-variants/C1/*.webp` 등(세미리얼 애니메 인물 일러스트, 문제 1과는 다른 화풍임에 유의).

## 문제 3 — 프리미엄 음성(TTS) 없는 표현 66개 (해결됨)

> 아래 내용은 2026-07-27 당시의 조사 기록이다. 표현 음성은 당시 67개를 생성했고, 2026-07-30에는 문장·팁·카드 변형까지 포함한 전체 통합 생성을 완료했다. 현재 `npm run audio:dry`의 신규 작업은 0이며, 매니페스트와 실제 MP3 파일을 독립 대조한 결과 요청 범주의 누락도 0이다. 카드 원본의 고유 음성 문자열 2,156개 중 단독 장음 기호 `ー` 1종은 의도적으로 발음 대상에서 제외된다.

`public/audio/manifest.json`(Azure TTS로 사전 생성된 음성 매니페스트, `scripts/generate-audio.mjs`가 만듦)을 전체 466개 표현(Phrase)과 대조한 결과, **66개(약 14%)가 미생성** 상태다. 이 표현들은 지금 브라우저 Web Speech API 폴백(`src/tts.ts`)으로만 재생되며, 품질·안정성이 프리미엄 음성보다 떨어진다.

- 특히 **C51~C53(지진·병원접수·미아찾기, 안전 콘텐츠) 관련 표현 전부**가 미생성 상태 — 안전 상황에서 음성 안내 신뢰도가 가장 중요한데 정작 가장 뒤처져 있다.
- C54(택배 재배달) 신규 표현 6개도 미생성(이미 알려진 사항, 2026-07-26 사용자 확인 후 보류 결정됨).
- 나머지는 최근 콘텐츠 감수(`p_new_*` 접두사)로 추가된 표현들과 몇몇 개별 표현(와이파이 연결, 우산 분실, 관심 없어요 등).

## 검증 방법 (작업 완료 후)

- 이미지: 새 파일을 정확한 경로/파일명에 넣은 뒤 `npm run dev`로 실행, 앱에서 실제로 해당 화면(간판·메뉴 카드, C51~C54 미션 세션)을 열어 이미지가 뜨는지 육안 확인. `.webp` 형식 유지.
- 오디오: `npm run audio:dry`가 `new jobs : 0`인지 확인하고, `public/audio/manifest.json`의 경로가 실제 MP3 파일로 연결되는지 대조한 뒤 `npm run lint:content`로 전체 콘텐츠를 검증.
- 캐릭터 의상 교체: 기존 파일을 덮어쓴 뒤 시각적으로 뭉·양이 확실히 구분되는지, 전체적으로 같은 화풍(3D chibi, 눈 크기·비율 등)이 유지되는지 확인.

## 범위 밖(이 문서가 다루지 않는 것)
- 마스코트 세계관·이름·설정 변경 — 의상만 다루며, 캐릭터 자체 재설계는 아님.
- session-variants(C1~C50)의 기존 이미지 — 이미 있으므로 대상 아님.
- 게임화 UI(카드 등급 아이콘 등, `public/gacha/`) — 조사 범위 밖.
