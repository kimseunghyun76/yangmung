# 페르소나 정의 (Usability Test)

> 이 문서는 합성 페르소나 기반 사용성 테스트를 위해 작성되었다. 실제 사용자 인터뷰 데이터가 아니다.

## 페르소나 1: 가나도 모르는 첫 일본 여행자
- 배경: 히라가나/가타카나를 전혀 모름. 일본 여행 처음.
- 핵심 과업: 완전 초보자 과정 찾기 → 한글 발음 보조 활성화 확인 → 편의점 봉투 요청 → 식당 주문 → 호텔 체크인 → 다음 날 복습.
- 평가 초점: 문자를 전혀 모르는 사용자가 중간에 포기할 가능성.

## 페르소나 2: 여행 5일 전 벼락치기 사용자
- 배경: 출국 5일 전. 시간이 없음.
- 핵심 과업: D-day 설정 → 5일 과정 찾기 → 식당/교통/호텔만 선택 학습 → 여행 당일 필요한 문장 빠르게 검색 → 비핵심 콘텐츠 건너뛰기.
- 평가 초점: 짧은 시간 안에 우선순위를 정해주는가.

## 페르소나 3: 귀는 트였지만 읽지 못하는 사용자
- 배경: 애니메이션/드라마로 듣기는 되지만 가나를 못 읽음.
- 핵심 과업: 듣기/읽기 수준 분리 진단 → 기초 표현 건너뛰기 → 편의점 직원 질문 듣기 → 비슷하게 들리는 표현 구분 → 가나+발음 보조 동시 사용.
- 평가 초점: 완전 초보로 오분류하지 않는가.

## 페르소나 4: 여행 경험은 있지만 말이 나오지 않는 사용자
- 배경: 일본 여행 경험 있음. 듣기/읽기는 어느 정도 되나 발화가 안 됨.
- 핵심 과업: 중급 진입 → 호텔 예약 오류 대응 → 대기시간 안내 응답 → 교환/환불 요청 → 직원 추가 질문에 이어 답하기.
- 평가 초점: 한 문장 암기를 넘어 대화 지속이 되는가.

## 페르소나 5: 가족 동반 안전 우선 여행자
- 배경: 아이/부모 동반. 안전이 최우선.
- 핵심 과업: 미아 상황 → 낙상 부상 상황 → 알레르기 설명 → 복용약 설명 → 병원 접수/긴급전화 정보.
- 평가 초점: 모든 긴급 과업 20초 이내 접근 가능한가.

## 페르소나 6: 일본 한 달 살기 사용자
- 배경: 단기 관광이 아닌 장기 체류.
- 핵심 과업: 장기체류 과정 선택 → 택배 재배송 요청 → 병원 초진 접수 → 분리수거 문의 → 시설 고장 전달 → 관광 이후 지속 콘텐츠 확인.
- 평가 초점: 단기 관광 콘텐츠와 장기 생활 콘텐츠 구분.

## 페르소나 7: 스마트폰에 익숙하지 않은 중장년 사용자
- 배경: 디지털 리터러시 낮음. 설명 없이 바로 사용.
- 핵심 과업: 설명 없이 첫 학습 시작 → 음성 재생 → 속도 조절 → 종료 후 재시작 → 복습 화면 찾기 → 여행 현장 문장 찾기.
- 평가 초점: 작은 글씨/아이콘/화면 전환/게임화 요소가 방해되는가.

## 페르소나 8: JLPT 시험 준비생
- 배경: 문법·한자·독해 시험 대비 목적.
- 핵심 과업: 앱 소개 확인 → 문법/한자/독해 과정 탐색 → 목적 부합 여부 판단.
- 평가 초점: 앱이 여행 회화 앱임을 명확히 전달하는가 (이 사용자를 만족시키는 기능 제안은 지양).
