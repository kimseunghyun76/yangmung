# 테스트 시나리오 (Usability Test)

## 공통 테스트 단계

### 1단계: 첫 진입
- 앱이 누구를 위한 앱인지 이해할 수 있는가
- 첫 화면에서 무엇을 해야 하는지 알 수 있는가
- 회원가입/설정 과정이 과도하지 않은가
- 여행 목적을 선택할 수 있는가
- 자신의 일본어 수준을 정확히 표현할 수 있는가
- 첫 학습까지 불필요한 단계가 많지 않은가

### 2단계: 수준 진단
- 완전 초보자를 정확히 구분하는가
- 듣기/읽기 능력을 별도로 고려하는가
- 애니메이션 시청 경험자를 과대/과소평가하지 않는가
- 중급 사용자가 지나치게 쉬운 과정에 배치되지 않는가
- 잘못 배치되었을 때 레벨 변경이 가능한가

### 3단계: 첫 학습
- 학습 목표가 명확한가
- 한 번에 제시되는 정보량이 적절한가
- 한글 발음/로마자/가나 표시가 수준에 적절한가
- 음성 재생/반복이 쉬운가
- 표현이 실제 여행에서 쓸 만한가
- 왜 이 표현을 배우는지 이해할 수 있는가
- 오답 피드백이 이해하기 쉬운가

### 4단계: 복습
- 무엇을 복습해야 하는지 이해할 수 있는가
- 복습 분량이 과도하지 않은가
- 틀린 표현이 적절히 재출제되는가
- 게임화 기능이 학습을 돕는가
- 포인트/가챠/연속학습이 부담이 되지 않는가
- 학습 중단 후 재개가 쉬운가

### 5단계: 여행 현장 사용
- 상황별 표현을 빠르게 찾을 수 있는가
- 편의점/식당/전철/호텔/쇼핑 상황이 직관적으로 구분되는가
- 문장을 직접 말하거나 화면을 보여줄 수 있는가
- 직원의 추가 질문에 대응 가능한가
- 검색 결과가 과도하거나 모호하지 않은가
- 오프라인/저속 연결 상황을 고려했는가

### 6단계: 돌발상황
- 병원/분실/지진/경찰/긴급전화 메뉴를 빠르게 발견할 수 있는가
- 긴급 문장이 짧고 명확한가
- 아이/노인/알레르기/복용약 상황이 구분되는가
- 불필요한 학습 절차를 요구하지 않는가
- 상대에게 바로 보여주거나 들려줄 수 있는가

## 증거 유형
- `[실행 확인]` 실제 앱 조작
- `[화면 확인]` 화면/스크린샷 확인
- `[코드 확인]` 구현 코드 확인
- `[콘텐츠 확인]` 학습 콘텐츠 데이터 확인
- `[추론]` 합리적 추정 (미확인)
- `[실사용자 검증 필요]` 사람 대상 검증 필요

## 심각도
- S0 차단 / S1 심각 / S2 중요 / S3 보통 / S4 경미
