# 페르소나 4: 여행 경험은 있지만 말이 나오지 않는 사용자

> 합성 페르소나 테스트 결과. 실제 사용자 데이터가 아님.

## 1. 페르소나 요약
일본 여행 경험이 있어 듣기·읽기는 어느 정도 되나, 실제 발화가 잘 안 되는 사용자.

## 2. 테스트 환경
- `[실행 확인]` 설정에서 "중급" 모드로 직접 전환해 실제 여행 미션(공항 입국심사, 15장) 세션을 처음부터 끝까지 진행하며 대화 흐름·문법 카드·퀴즈 방식을 확인.
- `[코드 확인]` 미션 콘텐츠 파일(`src/content/missions/*.ts`) 전수 스캔으로 이 페르소나가 요구하는 구체적 시나리오(호텔 예약 오류, 대기시간 응답, 교환/환불) 존재 여부 확인.

## 3. 수행한 과업
1. 중급 과정으로 진입
2. 호텔 예약 오류 상황 대응
3. 식당 대기시간 안내에 답하기
4. 교환 또는 환불 요청하기
5. 직원의 추가 질문에 이어서 답하기

## 4. 완료한 과업
- **중급 과정으로 진입**: `[실행 확인]` 설정 > 학습모드 > "중급" 카드 클릭 한 번으로 즉시 전환되고, "이제부터 실제 여행 미션이 시작돼요"라는 안내와 함께 홈 화면에 첫 여행 미션("공항 입국심사")이 노출됨.
- **직원의 추가 질문에 이어서 답하기(다회성 대화 확인)**: `[실행 확인]` 공항 입국심사 미션(15장 카드)을 실제로 진행한 결과, "목적은?→관광입니다→기간은?→일주일입니다→숙소는?→호텔입니다→직업은?→회사원입니다" 식으로 한 화제가 여러 턴에 걸쳐 자연스럽게 이어지는 구조를 확인함. 단발성 문장 암기에 그치지 않고 "대화의 흐름"(기억할 포인트: "목적 답하기→체류 기간→숙소 답하기→직업 답하기→마무리")을 명시적으로 안내함. **이 페르소나의 핵심 우려("한 문장 암기를 넘어 대화가 이어지는가")에 대해 긍정적 근거.**

## 5. 실패하거나 중단된 과업
- **호텔 예약 오류 상황 대응**: `[코드 확인]` 전체 53개 미션 시나리오 제목을 조사한 결과 "호텔에서 방 바꿔 달라고 하기"는 존재하나(방 변경 요청), "예약 자체가 잘못되었을 때(오버부킹, 예약 미확인 등) 대응"에 해당하는 전용 시나리오는 발견하지 못함(제목 기준 근사치 없음). **부분 실패** — 유사 상황은 있으나 정확히 일치하는 콘텐츠는 확인 안 됨.
- **식당 대기시간 안내에 답하기**: `[코드 확인]` "대기시간" 전용 시나리오는 발견하지 못함. 라멘집/식당 주문 미션에 대기 관련 대사가 포함되어 있을 가능성은 있으나 개별 스텝까지는 확인하지 못함. `[실사용자 검증 필요]`.
- **교환 또는 환불 요청하기**: `[코드 확인]` "환불·교환"(C41) 시나리오가 정확히 존재함을 확인. 그러나 이 미션은 **tier 5(고급심화)**이며 `unlockAfter: ['C40']`로 C40을 먼저 마쳐야 열리는 구조다. 미션 지도의 무작위 순차 오픈 방식(F3, persona-01/02 참고)까지 겹치면, 중급으로 갓 진입한 이 페르소나가 실제로 C41에 도달하기까지 상당한 학습량이 필요하다. **사실상 실패**(콘텐츠는 존재하나 도달 불가에 가까움).

## 6. 발견한 문제

### 문제 1: "경험자용" 트러블 대응 콘텐츠가 최상위 난이도에 몰려 있어 중급 진입 시점에 도달 불가
- **페르소나**: 4
- **발생 위치**: `src/content/missions/c41-c50-advanced.ts` (C41 환불·교환), 미션 지도
- **수행하려던 과업**: 교환 또는 환불 요청하기
- **증거 유형**: `[코드 확인]`
- **실제로 발생한 일**: 환불·교환 미션은 tier 5로 분류되어 C1~C40을 먼저 거쳐야 순번상 도달 가능한 위치에 있다. 그런데 tier5는 애초에 "고급심화·위기 대응"으로 설계되어 있어(`src/content/routes.ts` 주석 참고), 실제로는 "고급" 레벨 사용자를 겨냥한 콘텐츠다.
- **사용자가 기대할 행동**: 페르소나 4는 이미 여행 경험이 있고 "말이 안 나올 뿐" 실력은 중급 이상이므로, 트러블 대응류 콘텐츠에 상대적으로 빨리 도달하길 기대함.
- **문제가 되는 이유**: 실력과 무관하게 "중급으로 진입한 지 얼마 안 된 사용자"는 무작위 순차 오픈 특성상 tier5까지 도달하는 데 오랜 시간이 걸림 — 정작 이 페르소나가 가장 필요로 하는 콘텐츠가 가장 늦게 나옴.
- **재현 단계**: 설정에서 중급 전환 → 미션 지도 확인(1/53 오픈) → C41 언락 조건(C40 선행) 확인.
- **심각도**: S2 중요
- **발생 가능성**: 높음
- **영향받는 다른 페르소나**: 6(장기체류자 — 생활 트러블 대응도 유사하게 늦게 열릴 가능성)
- **개선 방향**: 실력 진단 결과에 따라 "트러블 대응" 같은 특정 태그의 미션을 조기 노출하는 방안 검토.
- **실제 사용자 검증 필요 여부**: 예.

### 문제 2: "대기시간 응답" 같은 세부 상황의 콘텐츠 존재 여부 불명확
- **페르소나**: 4
- **증거 유형**: `[코드 확인]` (제목 기준 조사, 스텝 단위 전수 확인은 아님)
- **실제로 발생한 일**: 53개 미션 제목 중 "대기시간"에 해당하는 전용 항목을 찾지 못함.
- **문제가 되는 이유**: 식당류 미션(라멘집/이자카야/스시집 등 다수 존재) 내부에 대기 관련 대사가 포함되어 있을 가능성이 있어 단정할 수 없음.
- **심각도**: `[추론]` S3 보통
- **실제 사용자 검증 필요 여부**: 예 — 코드 분석의 한계이므로 실제 미션 스텝을 모두 열어 확인 필요.

## 7. 학습 콘텐츠 적합성
- `[실행 확인]` 공항 입국심사 미션에서 확인한 다회성 대화 구조는 이 페르소나에게 강점. 문법 카드("~ますか", "~ください", "조사 を")가 상황 카드 사이사이 자연스럽게 삽입되어, 단순 암기를 넘어 문형 이해를 돕는 점도 긍정적.

## 8. 화면 및 조작 적합성
- `[실행 확인]` 학습모드 전환이 매우 즉각적이고 직관적(원클릭). 승급 시험 없이도 원하는 레벨로 바로 진입 가능해 "실력은 있는데 시스템이 안 믿어준다"는 답답함이 없음.

## 9. 여행 현장 활용 가능성
- `[코드 확인]` 트러블 대응류 콘텐츠(환불/교환 등)가 tier5에 몰려 있어, 실제 여행 중 갑자기 발생하는 트러블 상황에 대응할 문장을 앱에서 아직 "열어보지" 못했을 가능성이 높음(F3 구조적 문제와 결합).

## 10. 실제 사용자에게 검증해야 할 가설
- 여행 경험자가 실제로 "말이 안 나오는" 이유(어휘 부족 vs 발화 자신감 부족)에 이 앱의 접근(문형+상황+반복)이 효과적인지.
- tier5 콘텐츠까지 도달하는 데 걸리는 실제 세션 수.

## 12. 이 페르소나에게 앱을 추천할 수 있는가
**가능.** 다회성 대화 흐름과 문법 미니팁의 결합은 이 페르소나가 우려하는 "한 문장 암기의 한계"를 실제로 넘어서고 있음을 직접 확인했다. 다만 이 페르소나가 가장 필요로 하는 "트러블 대응" 콘텐츠가 난이도 최상위(tier5)에 몰려 있고 무작위 순차 오픈 구조와 겹쳐 실제 도달까지 오래 걸릴 수 있다는 점은 아쉬움으로 남는다.
