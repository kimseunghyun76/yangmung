## 남은 것 (최종 정리)
1. **입문·기본 레벨 미션 전면 잠금** — 사용자 확인을 거쳐 **그대로 유지하기로 결정**. 더 이상 열린 과제 아님(설계 의도 확인 완료).
2. **"도감" 용어** — 내비게이션 라벨만 순화 완료. 화면 내부(가챠 페이지 제목 등)는 범위 밖으로 유지.
3. **C54 원어민 검수 + `npm run audio` 실행** — 사용자가 직접 Azure 자격증명으로 실행 필요. 그 전까지 브라우저 TTS 폴백으로 정상 동작.
4. **실사용자 검증 필요 항목**(코드로 해결 불가, 실제 사용자 대상 검증 필요): 긴급 버튼 실제 발견률, TTS 재생 안정성, C54 음질 체감, 그리고 이번에 추가된 "우선 학습 카테고리" 기능의 실제 발견성(미션 지도 안에 위치해 있어 그 화면에 들어가야 보임).

## 결론
round3까지 남아있던 항목 중 코드로 해결 가능한 것은 모두 조치했다(카테고리 지정 오픈, D-day 자동 추천, 라벨 순화). 설계 의도가 있는 항목(미션 잠금)은 사용자 확인 후 유지로 확정했고, 외부 자격증명이 필요한 항목(C54 오디오)과 실사용자 검증 항목은 성격상 이번 라운드에서 코드로 처리할 수 있는 범위 밖이라 남겨두었다.
