## 1. 반복적으로 발견된 문제 (3명 이상 페르소나에 공통)

### 1-A. 미션(여행 회화 콘텐츠)이 잠겨 있거나, 열려도 특정 미션을 지정해 접근할 수 없음
- **영향받는 페르소나**: 1, 2, 4, 5, 6, 7 (6명)
- **증거 유형**: `[실행 확인]` + `[코드 확인]`
- **핵심 내용**:
  1. 입문·기본 레벨에서는 미션 탭 전체가 잠김 (`missionsLocked`, `src/App.tsx:109`) — "미션은 중급부터 열려요" 안내만 표시.
  2. 설정에서 학습모드를 "중급"으로 직접 전환하면 즉시 우회 가능하나(`[실행 확인]`), 전환 후에도 53개 장면 중 단 1개만 열려 있고 나머지는 "학습할수록 무작위로" 열림(`src/views/Map.tsx:36-39`).
  3. 홈 화면의 편의점/식당/전철/호텔 미리보기 카드조차 클릭 시 단순히 미션 지도로 이동할 뿐, 해당 카테고리를 우선 오픈해주지 않음(`src/views/Home.tsx:289`).
  4. 복습 화면의 검색(표현/장면별)은 "이미 학습(노출)한 콘텐츠"만 대상이라, 아직 배우지 않은 특정 미션(예: 응급, 환불·교환)을 검색해서 찾는 것 자체가 불가능.
- **왜 반복되는가**: 이 구조는 특정 페르소나만의 문제가 아니라 앱의 **핵심 미션 오픈 알고리즘 자체**이므로, "특정 상황의 문장을 지금 당장 원하는" 모든 사용자 유형(초보자, 벼락치기, 경험자, 안전 최우선, 장기체류, 중장년)에게 형태만 다르게 나타남.

### 1-B. 여행 스타일/여행 목적 선택이 실제 학습 커리큘럼에 반영되지 않음
- **영향받는 페르소나**: 2, 6 (2명 — 참고용으로 함께 기재. 아래 "페르소나별 고유 문제"에도 개별 기술)
- **증거 유형**: `[실행 확인]` + `[코드 확인]`
- **핵심 내용**: 홈 화면의 "당일치기/단기 여행/한달살기" 배너는 문화·여행팁 라이브러리에서 태그가 일치하는 팁 몇 개(장기체류는 6개)만 필터링할 뿐, 미션 순서·분량·난이도에는 전혀 영향을 주지 않음.

## 3. 핵심 타겟 적합성 평가

**핵심 타겟 정의**: "일본어와 가나를 모르지만 1~2개월 뒤 배우자 또는 가족과 일본 자유여행을 가기 때문에 하루 10분씩 실제 필요한 표현을 준비하려는 40~50대 한국인 사용자"

이 타겟은 **페르소나 1(완전 초보)과 페르소나 7(중장년), 부분적으로 페르소나 5(가족 동반)의 교집합**에 해당한다.

**적합한 부분**:
- `[실행 확인]` 온보딩이 회원가입 없이 즉시 시작 가능하고, 목적("여행 일본어")을 첫 화면에서 명확히 전달함.
- `[실행 확인]` 가나 학습 카드가 한글 발음·니모닉·획순·따라쓰기까지 갖춰 완전 초보자를 세심하게 배려함.
- `[코드 확인]` 수준진단(16문항, 약 1분)과 미션 세션(카드 15~20장 내외)이 "하루 10분" 분량에 부합하는 규모로 설계되어 있음.
- 1~2개월이라는 여유 기간은 페르소나 2(5일 벼락치기)보다 훨씬 넉넉해, 가나 학습 → 승급이라는 정상 경로를 밟을 시간적 여지가 있음.

**부적합/위험한 부분**:
- `[코드+실행 확인]` 매일 10분씩 1~2개월(약 30~60세션)을 투자해도, 무작위 순차 오픈 구조상 tier5(위기 대응: 미아·지진·병원접수)까지 도달한다는 보장이 없음. 배우자·가족 동반이라는 조건상 안전 콘텐츠 접근성 문제(2절 참고)가 이 핵심 타겟에도 그대로 적용된다.
- `[추론]` 40~50대는 페르소나 7의 최고령층보다는 디지털 적응력이 있을 가능성이 높지만, 내비게이션 아이콘/텍스트 비일관 문제(2절)는 여전히 유효한 리스크로 남는다.
- `[코드 확인]` 여행 목적(자유여행, 배우자 동반)을 온보딩에서 전혀 묻지 않아, 이 핵심 타겟이 원하는 "우리 상황에 맞는" 맞춤 안내를 첫 진입부터 받지 못한다.

**종합 판단**: 가나 학습 설계 품질만 놓고 보면 핵심 타겟에 우수하게 부합하나, "실제 필요한 표현"(특히 안전 관련)에 도달하는 경로가 구조적으로 지연되는 문제가 핵심 타겟에도 그대로 적용되므로, **현재 구조로는 핵심 타겟 만족도에 상한선이 존재**한다.

## 4. 가장 먼저 수정해야 할 문제 (우선순위)

우선순위 기준: 핵심 여행 과업을 막는가 / 여러 페르소나에 반복되는가 / 여행 현장에서 문제를 일으킬 수 있는가 / 초보자의 학습 포기를 유발하는가 / 수정 비용 대비 효과가 큰가.

| 순위 | 문제 | 근거 |
|---|---|---|
| 1 | **안전·응급 미션(C51~53, C25~27)에 대한 전용 접근 경로 부재** | 핵심 과업 차단(S0, 페르소나5) + 여행 현장 리스크 최고 + 콘텐츠는 이미 존재하므로(전담 파일 c51-c52-crisis.ts, c53-lost-child.ts 확인됨) UX/게이팅 로직만 조정하면 되어 수정 비용 대비 효과가 매우 큼 |
| 2 | **미션 무작위 순차 오픈 → 특정 미션 지정/검색 불가 (1-A)** | 6개 페르소나에 반복 확인된 가장 광범위한 문제. 1번 문제의 근본 원인이기도 함 |
| 3 | **검색이 "이미 학습한 콘텐츠"로만 제한** | 미학습 콘텐츠 발견 경로가 전무해 2번 문제의 우회로조차 없음 |
| 4 | **입문·기본 레벨 미션 탭 전면 잠금** | 초보자가 첫 세션에 앱의 핵심 가치(여행 미션)를 전혀 체감하지 못해 학습 포기 유발 가능성(페르소나 1) |
| 5 | **여행 스타일 배너의 기대-실제 격차 (1-B)** | 반복 확인되었으나 안전 문제 대비 심각도는 낮음(S2) |

## 5. 수정하지 않아야 할 요구

- **JLPT 문법·한자·독해 체계적 학습 기능 추가** (페르소나 8): 앱의 핵심 포지셔닝("여행 실전 회화", README/PRD에 "JLPT N5는 덤"으로 명시)을 흐리는 방향. 온보딩이 이미 목적 불일치를 정직하게 전달하고 있으므로, 이 사용자군을 위한 별도 확장은 권장하지 않음.
- **장기체류자를 위한 대규모 "생활 회화" 신규 트랙 신설** (페르소나 6): 앱 정체성이 "여행"이므로 관광 이후 지속 콘텐츠를 크게 확장하는 것은 스코프 확장 리스크가 큼. 다만 택배 미션의 방향성 불일치(발송/수령) 같은 **소규모 정합성 보정**은 이 항목과 별개로 검토 가능.
- **개발자 도구("접근 제한 해제")를 정식 사용자 기능으로 승격**: 근본 원인(무작위 순차 오픈, 4절 우선순위 1·2번)을 해결하지 않은 채 이 토글만 사용자에게 노출하면 "안전장치가 숨겨진 치트키"라는 불투명한 경험만 남김. 우선순위 1·2번의 정식 해결책 안에서 자연스럽게 흡수되어야 할 사안.

## 6. 실제 사용자 테스트가 필요한 항목 (Claude의 분석만으로 판단 불가)

- 24시간 이상 경과 후 표현 회상률 및 복습 화면의 실제 유도 효과
- 실기기·실브라우저 환경에서 음성(TTS) 재생 성공률과 이해 명료도
- 중장년층의 실제 터치 조작 정확도, 버튼/아이콘 인지율(특히 아이콘 없는 텍스트 탭 vs 텍스트 없는 아이콘 버튼)
- 여행 전 1~2개월간 매일 10분 학습을 실제로 지속하는 비율과 이탈 시점
- (우선순위 1·2 개선 후) 응급 상황을 가정한 탐색 속도 재검증 — 목표 20초 이내 달성 여부
- 일본 현지에서 실제 미션 문장을 사용했을 때의 과업 성공률(점원 반응, 대화 지속 가능 여부)
- 무작위 순차 오픈 방식에 대한 사용자의 정서적 반응 — "다음에 뭐가 나올지 궁금한 재미" vs "원하는 걸 못 찾는 답답함" 중 실제 우세 반응
- 여행 스타일 배너의 실제 인지율과, 선택 후 기대와 실제 경험의 격차가 만족도에 미치는 영향
