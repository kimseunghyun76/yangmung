## 새로 발견된 문제
- `src/views/Home.tsx`의 `TravelPurposeBanner`에서 React Hooks 규칙 위반(early return 뒤 `useMemo` 호출) — 사용자가 별도로 작업 중이던 미커밋 코드에서 발견. 사용자 확인 후 이번 라운드에 함께 수정 완료(위 표 참고). 사용성 테스트 범위의 발견은 아니라 심각도 등급은 매기지 않음.

## 핵심 타겟("40~50대, 가나 모름, 1~2개월 준비") 재평가
1차에서 지적한 "1~2개월 준비해도 안전 콘텐츠(위기 대응) 도달을 보장 못 함" 리스크가 이번 라운드로 **구조적으로 해소**되었다 — 배우자·가족 동반 시 가장 우려되는 미아·지진·병원 상황에 학습 진도와 무관하게 즉시 접근 가능하다. 내비게이션 일관성 개선도 이 타겟(디지털 숙련도가 아주 높지는 않은 40~50대)에 직접적으로 도움이 된다. 다만 편의점·식당 등 **일반 관광 기초 미션의 입문·기본 레벨 잠금**은 그대로이므로, 이 타겟이 "오늘 당장 여행 회화를 써보고 싶다"는 기대를 첫 세션에 완전히 충족하지는 못한다.

## 남은 후속 과제 (우선순위 제안)

2026-07-26 라운드에서 아래 4건이 모두 완료됨: C41~C50 중 환불·교환(C41) tier 재검토, 긴급연락처 사실 재검증, D-day 입력 기능, 택배 재배송 콘텐츠 신규 제작. 남은 항목:

1. **C54(택배 재배달 신청) 원어민 검수 + `npm run audio` 실행** — 신규 문장이 아직 검수 전이고 프리미엄 음성(Azure)이 생성되지 않은 상태. `npm run audio`는 `AZURE_SPEECH_KEY` 등 사용자 보유 자격증명이 필요해 이번 세션에서 직접 실행하지 않음.
2. **C42~C50(순수 고급심화, 자판기·ATM·오마카세 등) tier 유지 여부 재검토** — 이번엔 페르소나 4의 직접 불만 대상(C41)만 옮겼고, 나머지 9개는 실제로 tier5(가장 늦게 열림)가 적절한 고급 콘텐츠라 판단해 그대로 둠. 필요 시 재검토.
3. **D-day 기반 커리큘럼 압축/우선순위 알고리즘** — 입력·표시(완료)를 넘어, 남은 일수에 따라 학습 순서를 재구성하는 것은 별도 규모의 작업으로 남겨둠.
4. **카테고리 지정 미션 오픈(무작위 순차 오픈의 대안)** — persona-02가 원하는 "식당·교통·호텔만 우선 학습"은 여전히 미해결. 응급 콘텐츠만 상시 접근 진입점(긴급 화면)으로 해결된 상태.
5. **"도감" 등 게임화 용어 재검토** — 범위 밖 유지.
6. **실사용자 검증 항목**(1차 summary.md 6절 그대로 유효) — 특히 "긴급" 버튼의 실제 응급 상황 발견률, TTS 재생 안정성, C54의 브라우저 TTS 폴백 음질 체감.
