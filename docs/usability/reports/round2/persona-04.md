## 문제 1 후속 갱신 (1차: S2 중요 "경험자용 트러블 대응 콘텐츠가 최상위 난이도에 몰려 있음") → 해결
- **판정**: **해결**. `[코드+실행 확인]` `src/content/missions/index.ts`의 `TIER` 맵에서 C41(환불·교환)을 5→4로 재배정하고 `src/content/routes.ts` "문제 해결" 루트에 등록. `npm run test`(missionCoverage.test.ts 포함, tier/ROUTES 정합성 자동 검증) 295개 테스트 전부 통과.
- **실행 확인**: 설정에서 "중급"으로 전환 + 개발자 도구 "접근 제한 해제"로 전체 장면을 열어 미션 지도에서 "환불·교환"(쇼핑몰 서비스 데스크) 카드가 다른 tier4 트러블 콘텐츠(병원·분실·긴급 등)와 같은 목록에 정상적으로 나타남을 확인.
- C25~27과 동일한 tier로 합류했으므로, 정상 진행(중급 floor=1) 시에도 tier5(C42~C50)보다 훨씬 이른 단계에서 자연스럽게 만날 가능성이 높아짐.
- **심각도 변화**: S2 → 해결.
