# 페르소나 7 (2차): 스마트폰에 익숙하지 않은 중장년 사용자

> 합성 페르소나 재테스트. 1차 보고서: [../persona-07.md](../persona-07.md).
> **범위**: 내비게이션 아이콘/텍스트 일관성 재검증.

## 재검증 결과

### 문제 1 (1차: S3 보통 "상단 내비게이션이 아이콘 없이 텍스트만, 우측 버튼은 반대로 아이콘만") → 해결
- **판정**: **해결**. `[실행 확인]` 데스크톱·모바일(375px) 화면 모두에서 우측 유틸리티 버튼(긴급/주야/팁/가이드/설정)에 아이콘과 함께 짧은 한글 라벨("긴급", "주야", "팁", "가이드", "설정")이 아이콘 아래 상시 노출됨을 확인. 좌측 5개 탭(홈/학습/미션/복습/도감)은 원래도 텍스트가 있었으므로, 이제 좌우 모두 "아이콘+텍스트" 또는 "텍스트"로 통일된 시각 언어를 사용.
- **심각도 변화**: S3 → 해결.

### 문제 2 (1차: S3 보통 "'도감' 등 게임화 용어가 직관적이지 않음") → 미해결
- **판정**: 이번 범위에 포함되지 않아 **미해결**. `도감` 라벨 자체는 변경하지 않음(용어 변경은 다른 화면·컬렉션 기능 명칭과 연쇄적으로 얽혀 있어 이번 소규모 개선 범위에서 제외).

### 문제 3 (1차: `[실사용자 검증 필요]` "오디오 재생 신뢰성") → 변경 없음
- 이번 라운드에서 TTS 로직 자체는 건드리지 않아 1차와 동일하게 실사용자 검증이 필요한 상태로 남음.

## 신규 확인: "긴급" 버튼이 오히려 추가 학습 부담 없이 이해하기 쉬움
- `[실행 확인]` "긴급" 버튼은 경고 삼각형 아이콘 + 굵은 빨간 글씨 "긴급" 라벨로 다른 버튼보다 시각적으로 확실히 구분됨. 클릭 시 화면 진입도 즉각적(모달 없이 화면 전환)이라, 디지털 숙련도가 낮은 사용자도 "누르면 뭔가 긴급한 도움이 나오는구나"를 직관적으로 알아챌 가능성이 높음. `[추론]`.
