# 페르소나 6 (2차): 일본 한 달 살기 사용자

> 합성 페르소나 재테스트. 1차 보고서: [../persona-06.md](../persona-06.md).
> **범위**: 택배 미션 문구 수정, 여행 스타일 배너 카피, 긴급 화면(병원 관련) 재검증.
> **2026-07-26 추가 후속조치**: 택배 재배달 신청 신규 미션(C54) 제작 완료 — 아래 "문제 1 후속 갱신" 참고.

## 문제 1 후속 갱신 (1차: S3 보통 "택배 미션이 이름과 달리 발송 전용 — 재배송 요청과 방향이 반대") → 해결
- **판정**: **해결**. `[실행 확인]` "택배 재배달 신청"(C54) 신규 미션을 제작해 실제로 처음부터 끝까지 진행 확인 — 부재중 택배 스티커를 보고 전화로 재배달 신청 → 희망 날짜 → 희망 시간대 → 완료 확인의 4단계 대화가 정상 작동하며, 정답 선택 시 올바른 피드백("자연스러워요")까지 확인.
- C12(발송 전용, 문구는 1차 후속에서 이미 명확화됨)와 C54(수령·재배송)로 방향이 분리되어, 장기체류자의 원래 니즈("택배 재배송 시간 변경 표현 찾기")가 실제 대화형 콘텐츠로 충족됨.
- **한계(사용자 확인 후 진행)**: 이 미션의 일본어 문장은 원어민 검수 전 상태이며, 새 표현 6개는 사전 생성 음성(Azure) 없이 브라우저 TTS(Web Speech API) 폴백으로만 재생됨 — 다른 미션과 음질 차이가 날 수 있음. 배포 전 원어민 검수와 `npm run audio`(Azure 자격증명 필요, 사용자가 직접 실행) 실행을 권장.
- `npm run lint:content`(V1~V22 전체) · `npm run test`(missionCoverage 포함) · `npm run typecheck` 전부 통과.
- **심각도 변화**: S3 → 해결(오디오 품질·원어민 검수는 별도 후속 과제로 명시).

### 문제 2 (1차: S2 중요 "여행 스타일 선택이 커리큘럼에 반영되지 않음") → 완화
- **판정**: persona-02 2차와 동일한 근거로 **완화**(기대치 조정, 기능 추가는 아님). `[실행 확인]` 홈 배너에서 "한달살기(장기 체류)" 선택 시 문구가 실제 동작과 일치하게 조정됨을 확인.
- **심각도 변화**: S2 → S3.

### 신규 확인: 병원 관련 응급 콘텐츠 접근성 개선
- `[실행 확인]`(persona-05 2차에서 실행 확인) 긴급 화면을 통해 병원 접수(C52)·병원 증상설명(C25)·약국(C6)에 레벨과 무관하게 즉시 접근 가능해짐 — 장기체류자가 실제로 아플 때 유용한 콘텐츠의 도달성이 개선됨(원래 문제 3 "병원 초진 접수 표현 찾기"와 직결).
