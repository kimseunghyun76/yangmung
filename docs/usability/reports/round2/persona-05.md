# 페르소나 5 (2차): 가족 동반 안전 우선 여행자

> 합성 페르소나 재테스트. 1차 보고서: [../persona-05.md](../persona-05.md).

## 1. 페르소나 요약
1차와 동일 — 아이/노부모 동반, 안전·응급 대응이 최우선인 여행자.

## 2. 테스트 환경
- `[실행 확인]` 로컬 dev 서버, localStorage+IndexedDB 완전 초기화한 **신규 계정**에서 온보딩 모달을 닫자마자 바로 테스트(레벨 진단 스킵, "기본" 레벨 상태 — 1차와 동일하게 미션이 잠긴 최악의 조건).

## 3. 재검증한 과업
1차 5개 과업(미아·낙상·알레르기·복용약·병원접수/긴급전화) 중 1차에서 **S0(완전 차단)** 판정이었던 접근성 문제를 재검증.

## 4. 완료한 과업 (1차 대비 변화)
- **긴급 도움 화면으로 20초 내 접근**: `[실행 확인]` 신규 계정(레벨 "기본", 모든 미션 잠김 상태)에서 상단 내비게이션의 새 "긴급"(경고 삼각형 아이콘) 버튼을 클릭 → "긴급 도움" 화면 즉시 진입. 화면에 미아 찾기(C53)·지진·재난 대응(C51)·긴급상황 도움청하기(C27)·분실물과 길 도움요청(C26)·병원 접수(C52)·병원에서 증상설명(C25)·약국에서 약사기(C6) 7개 미션이 **잠금 여부와 무관하게** 모두 바로가기로 노출됨을 확인.
- **미아 찾기(C53) 실제 진입**: `[실행 확인]` "미아 찾기" 카드 클릭 → 미션 인트로 화면이 정상 로드되어 실제 대사(「子供を見失いました」 아이를 잃어버렸어요, 「五歳です」 다섯 살이에요, 「赤い服を着ています」 빨간 옷을 입고 있어요, 「放送で探してもらえますか」 방송으로 찾아주실 수 있나요? 등)를 확인. "기본" 레벨 계정(정상적으로는 미션 전체 잠김)임에도 정상 진입됨 — **잠금 로직을 완전히 우회한다는 설계가 실제로 동작함을 확인**.
- **소요 시간**: `[실행 확인]` 온보딩 모달 닫기 → 긴급 버튼 클릭 → 미아찾기 클릭까지 클릭 3회, 실측 수 초 내 — **1차에서 목표했던 "20초 이내" 요건을 충족**.
- **긴급연락처 참고(웹 검색 사실확인 반영)**: `[실행 확인]` 같은 화면 상단에 경찰 110 / 구급·화재 119(무료) / 주일본 대한민국 대사관 긴급연락처 +81-70-2153-5454(사건·사고, 야간·휴일용, 일본 현지 번호) / 외교부 영사콜센터 +82-2-3210-0404(24시간, 로밍 무료 컬렉트콜)까지 4개 연락처가 `tel:` 링크로 제공됨을 확인. 대사관 공식 사이트(overseas.mofa.go.kr) 기준 웹 검색으로 번호를 재검증해 처음 초안에 없던 "일본 현지에서 직접 거는 대사관 긴급연락처"를 추가함.

## 5. 남아있거나 새로 발견된 문제

### 문제 A (1차 문제 1, S0→해결): 안전 콘텐츠 접근 불가
- **판정**: **해결(Resolved)**. 근본 원인이던 "tier5 격리 + 무작위 순차 오픈만 존재"가 "상시 접근 가능한 전용 화면"으로 우회되어, 잠금 상태와 무관하게 즉시 접근 가능해짐.
- **심각도 변화**: S0 → 해결(신규 이슈 없음).
- **잔여 리스크**: `[추론]` "긴급" 아이콘 자체를 사용자가 실제 응급 상황에서 "저길 누르면 되겠다"고 순간적으로 인지할지는 코드로 보장할 수 없음 — 아이콘이 다른 유틸리티 버튼과 나란히 있어 평상시엔 눈에 띄지만, 패닉 상태에서의 실제 발견률은 `[실사용자 검증 필요]`.

### 문제 B (1차 문제 3, S2→해결): 긴급연락처 부재
- **판정**: **해결(웹 검색 사실확인 완료)**. 위 4절에서 확인한 대로 경찰(110)/구급·화재(119)/주일본대사관 긴급연락처(+81-70-2153-5454)/외교부 영사콜센터(+82-2-3210-0404) 4개 연락처가 긴급 화면에 상시 노출됨. 웹 검색(overseas.mofa.go.kr, 일본 정부 공식 안내 등)으로 번호 자체를 재검증했다 — 이전 라운드에서 `[실사용자 검증 필요]`로 남겨뒀던 항목을 해소.
- **잔여 리스크**: `[추론]` 공관 연락처는 개편될 수 있으므로, 실제 배포 시점에 한 번 더 대사관 공식 사이트에서 최신 번호를 확인하는 것을 권장(코드 변경이 아니라 운영 체크리스트 항목).

### 문제 C (신규 관찰, S4 경미): 긴급 화면 진입이 "레벨" 표시와 불일치해 보일 수 있음
- **발생 위치**: 긴급 도움 화면
- **증거 유형**: `[실행 확인]`
- **실제로 발생한 일**: "기본" 레벨(정상적으로는 미션 잠김)에서도 미션이 정상 진행되므로, 사용자가 홈 화면과 긴급 화면을 오가며 "왜 여기서는 되고 저기서는 안 되지?"라고 느낄 여지가 있음(의도된 예외이지만 화면 간 설명이 이어지진 않음).
- **문제가 되는 이유**: 사소하지만, 레벨 시스템에 대한 사용자의 정신모형과 충돌 가능.
- **심각도**: S4 경미
- **개선 방향**: (제안) 긴급 화면 상단 부제("레벨이나 진행 상황과 관계없이 지금 바로 연습하거나 참고할 수 있어요")가 이미 이 차이를 설명하고 있어 추가 조치는 낮은 우선순위.
- **실제 사용자 검증 필요 여부**: 예(낮은 우선순위).

## 6. 학습 콘텐츠 적합성
1차와 동일 — 콘텐츠 자체 품질(미아·지진·병원 시나리오 문장)은 이번 라운드에서도 상세히 재평가하지 않음(콘텐츠 변경 없음). 1차 평가 유지.

## 7. 화면 및 조작 적합성
- `[실행 확인]` 긴급 화면 UI는 GlassPanel/PrimaryAction 등 기존 디자인 언어를 그대로 재사용해 앱 전체와 톤이 일관됨. 미션 카드 7개가 세로 리스트로 스캔하기 쉬움.

## 8. 여행 현장 활용 가능성
- `[추론]` 접근성 문제가 해결되어 이론상 여행 현장에서도 즉시 참고 가능. 다만 오프라인 상태에서 `tel:` 링크나 미션 데이터 로드가 정상 동작하는지는 이번 테스트 환경(로컬 dev 서버)에서 검증 범위 밖 — `[실사용자 검증 필요]`.

## 9. 실제 사용자에게 검증해야 할 가설
- 긴급 상황을 가정한 패닉 상태에서 "긴급" 아이콘을 실제로 빠르게 찾아내는지.
- 긴급연락처 정보(특히 대사관 콜센터 번호)의 최신성·정확성.
- 오프라인/저속 연결 환경에서 긴급 화면 로드 속도.
