# 페르소나 1 (6차): 가나도 모르는 첫 일본 여행자

> 이력: [1차](../persona-01.md) → [2차](../round2/persona-01.md) → [3차](../round3/persona-01.md) → [4차](../round4/comparison.md) → [5차](../round5/persona-01.md).
> 6차는 round5 이후 누적된 대규모 변경(가챠 개편·학습/미션 지도 재구성·듣기 모드 신설·데일리 미션·미션 퀴즈 오버레이 개편·문형 정합성 수정·174개 응용 답변 콘텐츠 보강·전체 화면 후리가나 보완)을 반영한 라운드.

## 이번 라운드 반영 결과
- **후리가나가 한자 위에만, 앱 전체 일관 적용**: 지난 라운드에서 놓쳤던 긴급 화면·학습 미리보기·카드뽑기 선물 대사·문법 화면·단어장 등 12곳을 이번 세션에 전체 검수로 찾아 보완했다. 완전 초보자가 한자를 몰라도 읽는 법이 항상 함께 보인다. `[코드+실행 확인]`
- **데일리 미션(오늘 표현 5개)**: 홈 화면에 항상 보이는 진행률 한 줄이 생겨, 매일 조금씩 접속해도 "오늘 할 일"이 명확해졌다. 완료하면 카드뽑기로 연결. `[코드 확인]`
- **카드뽑기 단순화(항상 1장)**: 이전엔 1~30장까지 랜덤으로 뽑혀 초보자에게 오히려 혼란스러울 수 있었는데, 이제 항상 1장이라 결과를 이해하기 쉽다. `[코드 확인]`
- **미션 퀴즈 오버레이 개편**: 배경 이미지 하단에 질문·해석을 바로 얹어 공간을 절약 — 작은 화면에서 스크롤 없이 한눈에 보기 편해졌다. `[코드 확인]`
- **학습 지도 재구성**: 진행률 배너·추천·잠금 그리드로 정리되어 "다음에 뭘 해야 하는지"가 더 명확해졌다(가나 읽기 진도도 미션이 아닌 학습 탭으로 이동해 위치가 논리적으로 맞아짐). `[실행 확인]`
- **직접 확인**: 새 계정으로 편의점 미션(개발자 잠금해제) 세션 13장을 실제로 끝까지 진행 — 새 표현 카드마다 후리가나 정상 표시, "따라 말하기" 카드는 의도대로 가나만 표시, 완료 후 다음 단계 추천까지 콘솔 에러 없이 확인.

## 남은 문제
- 문법 카테고리의 예문(exampleJa) 114개는 가나 읽기 데이터 자체가 없어 후리가나를 못 붙인다 — 임의로 지어내면 발음 오류 위험이 있어 보류 중(후속 과제로 문서에만 남김).
- 일반 관광 기초 미션의 입문·기본 잠금은 여전히 설계 유지(4차에서 확정).

**조건부 가능 → 유지, 소폭 개선.** 읽기 보조의 사각지대가 크게 줄었고, 매일 조금씩 하게 만드는 동기 장치가 생겨 완전 초보자의 장기 이탈 위험이 낮아졌다.
