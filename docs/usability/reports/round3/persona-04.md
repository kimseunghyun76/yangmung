# 페르소나 4 (3차): 여행 경험은 있지만 말이 나오지 않는 사용자

> 3차 종합 재테스트. 이력: [1차](../persona-04.md) → [2차](../round2/persona-04.md).
> 이번 라운드 신규 반영: **중급→고급 승급 시험 오출제 버그 수정** — 이 페르소나에게 특히 중요한 변경.

## 재검증 결과

### 신규: 중급 승급 시험이 실제로 중급 커리큘럼을 테스트함
- `[코드+실행 확인]` 기존에는 "중급→고급 승급 시험"이 tier1~2 미션 회화만 출제했는데, 이는 중급 사용자가 실제로 순서대로 통과해 온 4단계(발음구분·작문·동사형태·받아쓰기)와 전혀 무관한 내용이었다. 이번에 발음구분·작문·받아쓰기(동사형태는 별도 퀴즈 시스템이라 제외)로 정확히 수정됨.
- 실제로 이 페르소나는 "여행 경험은 있지만 발화가 어려운" 사용자라 중급에 배치된 뒤 이 4단계를 순서대로 학습하게 되는데, 예전엔 승급 시험을 볼 때 전혀 다른 내용(미션 회화)이 나와 "내가 배운 게 시험에 하나도 안 나온다"는 혼란을 겪었을 것 — 이번 수정으로 이 혼란이 해소됨.
- 불합격 시에도 "작문에서 실수가 많았어요" 식으로 정확한 카테고리와 "작문 연습하러 가기" 바로가기가 제공되어, 무엇을 다시 연습해야 할지 즉시 알 수 있음.

### 변경 없음(1·2차 결과 유지)
- C41(환불·교환) tier4 재배정 — 2차에서 이미 해결 확인, 재검증 불필요.
- 다회성 대화 흐름, 문법 미니팁 — 콘텐츠 변경 없음.
