- 미아 찾기·지진/재난·긴급상황·분실물·병원 접수·병원 증상설명·약국 7개 미션 전부 잠금 여부와 무관하게 바로가기로 노출.
- **1차 S0(전체 테스트 최고 심각도) 문제가 여러 차례의 재검증(1차 발견 → 2차 수정 확인 → 3차 신규 계정 재현)에서 일관되게 해결 상태임을 확인.**
