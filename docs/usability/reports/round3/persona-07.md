# 페르소나 7 (3차): 스마트폰에 익숙하지 않은 중장년 사용자

> 3차 종합 재테스트. 이력: [1차](../persona-07.md) → [2차](../round2/persona-07.md).
> 이번 라운드 신규 반영: 승급 시험 결과 화면의 "친절한 가이드"가 특히 이 페르소나에게 유효.

## 재검증 결과
- 내비게이션 아이콘+라벨 일관성은 2차에서 이미 해결 확인, 변경 없음 — 유지.
- **신규**: 승급 시험에 불합격했을 때 뜨는 안내가 이제 "이번엔 가나 읽기에서 실수가 가장 많았어요"처럼 구체적인 이름 + 알기 쉬운 조언 문장 + "가나 표 다시 보기" 원클릭 버튼으로 제공된다. 디지털 숙련도가 낮은 사용자일수록 "다음에 뭘 눌러야 하는지" 스스로 추론하기보다 화면이 직접 알려주는 것이 중요한데, 이 개선이 정확히 그 역할을 한다. `[실행 확인]`(이번 세션에서 직접 재생 확인).
- 예전의 막연한 "이 부분을 다시 학습해 보세요 → 표현 2개 틀림" 같은 모호한 안내보다, 구체적 이름(발음 구분/작문/받아쓰기/기본 인사 등)과 원클릭 이동이 이 페르소나의 인지 부담을 크게 줄여준다.
