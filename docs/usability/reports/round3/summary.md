# 3차 종합 재테스트 요약

> 1차: [`docs/usability/reports/`](../), 2차: [`round2/`](../round2/), 3차: 본 디렉터리.
> 3차는 2차 이후 이번 대화에서 새로 발견·수정한 **승급 시험 콘텐츠 오출제 버그**(입문→기본, 기본→중급, 중급→고급 전체)와 **승급 시험 결과 화면의 친절한 약점 가이드**를 중심으로, 8개 페르소나 전원에 대해 변경 영향을 재검증한 델타 리포트다. 코드·콘텐츠가 바뀌지 않은 부분은 1·2차 결과를 그대로 승계했다.

## 완전히 해결된 것 (1차 → 3차 누적)
- **S0**: 안전·응급 콘텐츠(미아·지진·병원·약국) 학습 진도 무관 상시 접근 (`Emergency.tsx`)
- 내비게이션 아이콘/텍스트 비일관 (전 버튼 라벨 병기)
- 세션 중 JLPT 내부 식별자 노출
- 검색이 학습한 콘텐츠로만 제한 (잠금 힌트 카드로 발견 가능)
- 여행 스타일 배너 기대-실제 격차 (문구 정직화)
- 트러블 콘텐츠(C41 환불·교환) tier5 편중
- D-day 카운트다운 부재 (입력·표시)
- 택배 미션 방향 불일치 (C54 재배달 신청 신규 미션)
- **(3차 신규) 승급 시험이 학습하지 않은 내용을 출제하는 버그 — 입문/기본/중급 전 레벨**
- **(3차 신규) 시험 결과가 막연해서 다음 행동을 알 수 없던 문제 → 카테고리별 친절 가이드 + 바로가기**

## 아직 남은 것 (우선순위 제안)
1. **카테고리 지정 미션 오픈** — persona-02·persona-04가 원하는 "식당/교통/호텔 우선 학습"은 무작위 순차 오픈 그대로라 여전히 미해결 (응급 콘텐츠만 예외 처리됨).
2. **일반 관광 기초 미션의 입문·기본 레벨 전면 잠금** — 완전 초보자가 첫 세션에 "여행 회화"를 맛보고 싶다는 기대를 긴급 화면만으로는 완전히 채우지 못함.
3. **C54 원어민 검수 + `npm run audio` 실행** — 사용자 보유 Azure 자격증명 필요, 이번 세션에서 실행하지 않음.
4. **D-day 기반 커리큘럼 압축/우선순위 알고리즘** — 입력·표시는 완료, 학습 순서 재구성은 별도 규모 작업.
5. **"도감" 등 게임화 용어** — 범위 밖 유지.
6. **실사용자 검증 필요 항목**: 긴급 버튼의 실제 응급 상황 발견률, TTS 재생 안정성(특히 중장년 페르소나), C54 브라우저 TTS 폴백 음질 체감.

## 결론
1차에서 발견된 최고 심각도(S0) 문제와 이번 대화에서 사용자가 직접 겪고 제보한 승급 시험 오출제 버그(전 레벨) 모두 구조적으로 해결되었고, 자동 검증(295개 테스트, 콘텐츠 린트, 타입체크)과 신규 계정 기반 실제 조작으로 회귀 없음을 확인했다. 남은 과제는 대부분 "카테고리 우선 학습"처럼 원래도 별도 규모로 분리해뒀던 항목과, 실사용자 검증이 필요한 정성적 항목이다.
