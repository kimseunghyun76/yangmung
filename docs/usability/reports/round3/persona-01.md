# 페르소나 1 (3차): 가나도 모르는 첫 일본 여행자

> 3차 종합 재테스트. 이력: [1차](../persona-01.md) → [2차](../round2/persona-01.md).
> 이번 라운드에 추가된 변경: D-day, C54 신규 미션, **승급 시험 오출제 버그 수정 + 친절한 약점 가이드**(이번 대화에서 신규 발견·수정).

## 재검증 결과 (신규 계정, `[실행 확인]`)
- **온보딩**: 4단계로 확장됨(수준진단/맞춤학습/자동복습/여행스타일 팁) — 여행 스타일 배너의 존재를 온보딩에서 미리 안내해 발견성이 개선됨.
- **수준진단**: 전 문항 "모르겠어요" 응답 시 여전히 "설레는 첫 여행자"(입문)로 정확히 분류됨. 상황회화 안내 배너("몰라도 정상이니 편하게 패스하세요")도 그대로 유지.
- **긴급 도움 화면**: 입문·0% 진행 상태에서 "긴급" 아이콘 클릭 → 즉시 진입, 미아찾기·지진·병원·약국 등 7개 미션 + 연락처 4종 전부 정상 노출. 1차의 S0 문제 해결이 이번에도 재확인됨.
- **레벨 진도**: 히라가나 → 가타카나 → 기본인사 3단계, 미션 잠금 안내 문구 모두 1차와 동일하게 유지(정상).

## 신규 반영: 승급 시험 정상화
- 입문 단계를 다 마치고 "입문→기본 승급 시험"을 보면, **이제는 가나 읽기/듣기와 기본 인사만 출제됨**(이전엔 중급 전용인 발음구분·작문이 섞여 나오는 버그가 있었음 — 이번 대화에서 사용자가 직접 겪고 리포트해 발견·수정).
- 불합격 시 "이번엔 가나 읽기에서 실수가 가장 많았어요(N개)"처럼 1순위 약점을 짚어주고, 카테고리별 조언 문구 + "가나 표 다시 보기" 바로가기 버튼까지 제공 — 완전 초보자가 시험에서 막혀도 다음에 뭘 해야 할지 헤매지 않음.

## 남은 문제 (1차 그대로 유효)
- 편의점·식당 등 **일반 관광 기초 미션**은 여전히 입문·기본 레벨에서 전면 잠금(응급 콘텐츠만 예외). 첫 세션에 "여행 회화"를 맛보고 싶다는 기대는 긴급 화면이 부분적으로만 충족.

## 추천 여부
**조건부 가능 → 유지.** 안전망(긴급 화면)과 학습 피드백(승급시험 가이드)이 모두 갖춰져, 완전 초보자가 길을 잃지 않고 계속 진행할 수 있는 기반이 마련됐다.
