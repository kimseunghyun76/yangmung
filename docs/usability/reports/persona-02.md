# 페르소나 2: 여행 5일 전 벼락치기 사용자

> 합성 페르소나 테스트 결과. 실제 사용자 데이터가 아님.

## 1. 페르소나 요약
출국까지 5일 남은 시점에서 벼락치기로 필수 표현만 골라 배우려는 사용자.

## 2. 테스트 환경
- `[코드 확인]` 로컬 dev 서버, 신규 사용자 상태 + 코드 리딩(`Home.tsx`, `routes.ts`, `settings.ts`) 병행.

## 3. 수행한 과업
1. 출국까지 남은 기간(D-day) 설정
2. 5일 학습 과정 찾기
3. 식당·교통·호텔만 선택해 학습
4. 여행 당일 필요한 문장 빠르게 검색
5. 중요하지 않은 콘텐츠 건너뛰기

## 4. 완료한 과업
- 없음 — 이 페르소나가 명시적으로 원하는 5개 과업 중 **정확히 부합하는 기능은 하나도 발견되지 않음**. 가장 근접한 대체 경로만 존재.

## 5. 실패하거나 중단된 과업 (대체 경로 포함)

### 과업 1: D-day 설정
- `[코드 확인]` 코드베이스 전체에 출국일/D-day 입력 필드나 카운트다운 기능이 존재하지 않음(전체 검색 결과 없음). **실패.**

### 과업 2: 5일 학습 과정
- `[코드 확인]` "N일 완성" 같은 기간 기반 커리큘럼은 없음. 가장 가까운 대체는 홈 화면 하단의 "이번 여행은 어떤 스타일이에요?" 배너에서 "단기 여행(2~5박)"을 선택하는 것이나(`[실행 확인]`), 이는 문화·여행팁(grammar.ts) 중 태그가 일치하는 팁만 골라 보여주는 필터일 뿐, 미션 순서·난이도·분량을 재구성하지 않는다(`[코드 확인]`, `src/content/grammar.ts`의 `g_trip_*` 태그). **실패** (대체 기능은 있으나 목적을 충족 못함).

### 과업 3: 식당·교통·호텔만 선택 학습
- `[실행+코드 확인]` 홈 화면에는 편의점/식당/전철/호텔 미리보기 카드가 있지만, 잠긴 상태에서 클릭하면 단순히 미션 지도로 이동할 뿐(`Home.tsx:289` `onClick: () => (locked ? onMap() : onPracticeScene(m.id))`), 특정 카테고리를 "우선 순위로 지정"하는 기능이 아니다. 미션 지도(`Map.tsx`)의 실제 오픈 방식은 53개 장면 중 무작위 순차 오픈이라 사용자가 "식당·교통·호텔만" 골라 잠금 해제할 방법이 없다. **실패.**

### 과업 4: 여행 당일 필요한 문장 빠르게 검색
- `[실행 확인]` 복습(Review) 화면의 "표현" 탭에 검색창(표현·뜻·로마자 검색)이 있으나, **이미 학습(노출)한 표현만** 검색 대상이 된다(빈 상태에서 "해당 표현이 없어요" 확인). 아직 배우지 않은 편의점/식당 표현은 검색해도 나오지 않는다. **실패.**

### 과업 5: 중요하지 않은 콘텐츠 건너뛰기
- `[코드 확인]` 학습모드를 "가나만"으로 좁히거나 "고급"으로 올려 가나 드릴을 건너뛰는 등 모드 단위의 굵은 건너뛰기는 가능하나(F7, persona-01 참고), 미션 단위·주제 단위의 세밀한 건너뛰기(예: "쇼핑·패션은 건너뛰고 응급만")는 지원하지 않는다. **부분 실패.**

## 6. 발견한 문제

### 문제 1: 여행 스타일 배너가 커리큘럼에 영향을 주지 않음(라벨 사기 위험)
- **페르소나**: 2 (6에도 동일 영향)
- **발생 위치**: 홈 화면 "이번 여행은 어떤 스타일이에요?" 배너, `src/views/Home.tsx`, `src/content/grammar.ts`
- **증거 유형**: `[실행+코드 확인]`
- **실제로 발생한 일**: "단기 여행(2~5박)"을 선택해도 미션 순서·분량·난이도는 전혀 바뀌지 않고, 단지 문화팁 라이브러리에서 태그가 맞는 팁 몇 개만 더 보임.
- **사용자가 기대할 행동**: 벼락치기 사용자는 "단기 여행" 선택이 곧 "짧고 굵은 커리큘럼"으로 이어지길 기대함.
- **문제가 되는 이유**: 기대와 실제 동작의 불일치. 배너의 존재 자체가 "이 앱이 여행 스타일별 맞춤 학습을 제공한다"는 암묵적 약속을 하는데, 실제로는 팁 필터링 수준에 그쳐 실망을 유발할 수 있음.
- **재현 단계**: 홈 화면 스크롤 → "단기 여행(2~5박)" 선택 → 미션 지도/레벨 진도 확인(변화 없음).
- **심각도**: S2 중요
- **발생 가능성**: 높음 (배너를 사용하는 모든 사용자)
- **영향받는 다른 페르소나**: 6(한달살기 — 장기체류 전용 학습 트랙을 기대하지만 실제로는 팁 6개만 추가)
- **개선 방향**: 배너 문구를 "맞춤 팁을 보여드려요" 수준으로 기대치를 낮추거나, 실제로 미션 추천 순서에 반영하는 기능을 검토.
- **실제 사용자 검증 필요 여부**: 예 — 배너 문구만으로 사용자가 "커리큘럼이 바뀐다"고 오해하는지 여부.

### 문제 2: 카테고리 지정 불가능한 무작위 미션 오픈 (persona-01의 F3와 동일 근본 원인)
- **페르소나**: 2
- **발생 위치**: `src/views/Map.tsx:36-39` (`lockHint`), 미션 지도
- **수행하려던 과업**: 식당·교통·호텔만 선택해 학습
- **증거 유형**: `[실행+코드 확인]`
- **실제로 발생한 일**: 열린 장면을 충분히 학습해야 "무작위로" 다음 장면이 열림. 사용자가 특정 카테고리를 지정할 UI가 전혀 없음.
- **사용자가 기대할 행동**: 시간이 부족한 사용자는 "이번엔 전철·호텔만" 같은 선택적 학습을 기대함.
- **문제가 되는 이유**: 5일이라는 제한된 시간에 무작위 오픈에 기대야 하므로, 정작 필요한 카테고리가 마지막까지 안 열릴 위험이 있음(순수 확률 문제).
- **재현 단계**: 미션 지도 진입 → 열린 장면 1개 확인 → 잠긴 장면 목록에서 특정 미션 선택 불가 확인.
- **심각도**: S1 심각
- **발생 가능성**: 높음
- **영향받는 다른 페르소나**: 1, 4, 5, 6 (원하는 특정 상황에 도달하려는 모든 사용자)
- **개선 방향**: 카테고리(장소) 필터 기반 선택적 오픈 옵션 검토.
- **실제 사용자 검증 필요 여부**: 예.

### 문제 3: D-day/카운트다운 부재
- **페르소나**: 2
- **증거 유형**: `[코드 확인]`
- **실제로 발생한 일**: 출국일 입력 필드가 코드에 없음.
- **문제가 되는 이유**: "5일 남았다"는 급박함을 앱이 인지하지 못해 우선순위 조정에 전혀 반영되지 않음.
- **심각도**: S2 중요
- **발생 가능성**: 높음
- **영향받는 다른 페르소나**: 없음(이 페르소나 고유)
- **개선 방향**: D-day 입력 → 남은 일수 기반 콘텐츠 압축 로직 검토(장기 과제).
- **실제 사용자 검증 필요 여부**: 예.

## 7. 학습 콘텐츠 적합성
- `[코드 확인]` 콘텐츠 자체(문화팁 149개 여행실전, 언어학습 89개)는 여행 실전에 특화되어 있어 방향성은 맞음. 다만 "5일 안에 무엇부터"를 앱이 대신 정리해주지 않아, 사용자가 직접 방대한 콘텐츠 중 우선순위를 골라야 함.

## 8. 화면 및 조작 적합성
- `[실행 확인]` 여행 스타일 배너 UI 자체는 3개 버튼으로 단순하고 발견하기 쉬움(홈 화면 스크롤 시 바로 보임).

## 9. 여행 현장 활용 가능성
- `[실행+코드 확인]` 검색이 "이미 배운 것"으로 제한되므로, 5일 만에 원하는 만큼 진도가 안 나갔다면 여행 당일 검색 기능도 무용지물이 될 위험(F3와 연결).

## 10. 실제 사용자에게 검증해야 할 가설
- 벼락치기 사용자가 무작위 오픈 방식에서 실제로 필요한 카테고리에 도달하기까지 평균 며칠이 걸리는지.
- 여행 스타일 배너의 실제 존재 인지율과 기대-실망 격차.

## 12. 이 페르소나에게 앱을 추천할 수 있는가
**권하기 어려움 (현재 구조 기준).** 콘텐츠 품질과 방향성은 맞지만, "5일 안에 필요한 것만 빠르게"라는 핵심 요구를 지원하는 기능(D-day, 카테고리 선택, 커리큘럼 압축)이 전무하다. 시간에 쫓기지 않는 사용자에게는 적합하지만, 이 페르소나에게는 현재로선 다른 벼락치기용 자료와 병행을 권할 수밖에 없음.
