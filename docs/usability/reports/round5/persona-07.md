# 페르소나 7 (5차): 스마트폰에 익숙하지 않은 중장년 사용자

> 이력: [1차](../persona-07.md) → [2차](../round2/persona-07.md) → [3차](../round3/persona-07.md) → [4차](../round4/comparison.md).
> 이번 라운드는 이 페르소나에게 가장 크게 영향을 준 라운드 중 하나 — 아이콘 혼동·불필요한 메뉴 등 "무엇을 눌러야 할지 헷갈림" 계열 지적이 다수 반영됨.

## 이번 라운드 반영 결과
- **나가기(X)/이전 카드(화살표) 아이콘 구분**: 저디지털숙련 사용자가 가장 취약한 지점("이 버튼이 뭘 하는 버튼이지?")을 정확히 겨냥한 수정. 나가기는 관례대로 우측 X, 이전 카드는 좌측 화살표로 분리돼 혼동 소지가 크게 줄었다. `[실행 확인]`
- **'쓰기 시험' 배너 제거**: "시험"이라는 이름이 붙어 있어 부담스러웠는데, 애초에 히라가나·가타카나 단계 안에 이미 쓰기 연습이 있어 중복이었다 — 홈 화면의 선택지가 하나 줄어 인지 부담이 낮아짐.
- **홈 화면 수준진단 배너 버그 수정**: 진단을 다 마쳤는데도 배너가 계속 뜨는 것은 "내가 뭘 잘못했나?"하는 혼란을 주기 쉬운데, 이제 정확히 사라진다.
- **Done 화면 안내 강화**: "다음엔 무엇을 할까요" 섹션에 승급 시험과 어휘 학습 안내가 함께 명확히 제시돼, 다음 행동을 스스로 추론할 필요가 줄었다.

## 남은 문제
- TTS 재생 안정성은 여전히 `[실사용자 검증 필요]`.
- 미션 이미지·사운드 완성도는 문서화만 완료, 실제 개선은 후속 작업.

## 추천 여부
**조건부 가능 → 크게 개선.** "무엇을 눌러야 할지" 헷갈리게 하던 요소들이 이번 라운드에서 집중적으로 정리됐다. TTS 안정성만 실사용자 검증이 남았다.
