# 5차 종합 재테스트 요약

> 1차: [`docs/usability/reports/`](../), 2차: [`round2/`](../round2/), 3차: [`round3/`](../round3/), 4차: [`round4/`](../round4/), 5차: 본 디렉터리.
> 5차는 사용자가 앱을 실제로 써보며 직접 발견한 7건의 UX 지적사항을 반영한 라운드다. 착수 전 설계 충돌 소지가 없어 별도 확인 없이 바로 구현했다.

## 이번 라운드에 새로 고친 것

| 항목 | 내용 | 파일 |
|---|---|---|
| 나가기/이전 아이콘 구분 | 학습 화면 상단의 "나가기"와 "이전 카드"가 똑같은 화살표였던 것을 나가기=X 아이콘·우측, 이전 카드=화살표·좌측으로 분리 | `src/views/Session.tsx` |
| Done 화면 다음 학습 안내 | 기본 레벨(간판·메뉴 하나뿐)을 통과하면 승급 시험 배너만 뜨던 것 → "어휘 주제 계속 학습하기" 안내를 함께 노출. 처음엔 guide 배열에만 넣었다가, 실제 스테이지 세션이 항상 `isQuickPractice=true`로 시작된다는 것을 브라우저 검증 중 발견해 quick 배열에도 추가(그렇지 않으면 죽은 코드였음) | `src/views/Done.tsx` |
| 미션 이미지·사운드 조사 + 인수인계 가이드 | C51~C54(안전·택배 미션) 사진풍 삽화 전무, 66개 표현 프리미엄 음성 미생성, 마스코트 뭉(수컷)이 양과 동일한 여성 코딩 의상을 입은 문제를 조사해 ChatGPT가 이어받을 수 있는 가이드 문서·이미지 생성 매니페스트 작성. 코드로 즉시 가능한 부분(C51·C53 장소 아이콘·색상)은 바로 반영 | `docs/asset-gaps/README.md`(신규), `docs/generated-image-manifests/c51-c54-scenes.json`(신규), `src/views/scene.ts` |
| 승급 시험 결과 화면 배경 | 이전엔 텍스트만 있던 화면에 마스코트 배너 이미지 추가(합격/불합격 톤에 맞춰 색상 차등) | `src/views/PromotionResult.tsx` |
| 수준진단 배너 버그 수정 | 진단을 끝까지 마치고 "나중에/직접 고르기"를 눌러도 "진단 완료"가 기록되지 않아 홈 배너가 계속 뜨던 버그 수정 | `src/views/Placement.tsx`, `src/App.tsx` |
| 기본 레벨 첫 학습 재미 보강 | 기본 레벨의 첫 스테이지가 "간판·메뉴"(표지판 읽기)뿐이라 딱딱했던 것 → "기본 인사"를 첫 스테이지로 추가(입문과 진척은 완전 분리, 이미 배운 사용자는 빠르게 복습) | `src/learn/progression.ts` |
| '쓰기 시험' 배너 제거 | 히라가나·가타카나 단계에 이미 쓰기 연습이 포함돼 중복이던 홈 화면 배너 제거 | `src/views/Home.tsx`, `src/App.tsx` |

전체 검증: `npm run typecheck` / `npm run lint`(신규 경고 없음) / `npm run lint:content`(Phrase 466·Mission 55, V1~V22 하드실패 0) / `npm run test`(vitest, 16개 파일 **301개 테스트**) 모두 통과. 브라우저에서 신규 계정 기준 온보딩→진단→기본 레벨 2단계 완주→승급 시험까지 실제로 조작해 7건 전부 육안 확인했다.

## 완전히 해결된 것 (누적, 1~5차)
- S0: 안전·응급 콘텐츠 상시 접근, 내비게이션 아이콘/텍스트 비일관, JLPT 내부 ID 노출, 검색 제한, 여행 스타일 배너 기대치, C41 tier, D-day, 택배 재배달 미션, 승급 시험 오출제(전 레벨), 카테고리 지정 미션 오픈, D-day 자동 추천
- **(5차 신규)** 나가기/이전 아이콘 혼동, 기본 레벨 승급시험 직행 문제, 승급 시험 화면 배경 부재, 진단 완료 배너 버그, 기본 레벨 첫인상 문제, 쓰기시험 배너 중복

## 아직 남은 것
1. **미션 이미지·사운드 자산** — C51~C54 사진풍 삽화, 66개 표현 프리미엄 음성, 마스코트 의상 구분(뭉≠양)은 `docs/asset-gaps/`에 상세히 문서화 완료. 실제 생성은 이미지 생성 가능한 세션(ChatGPT 등)이 이어받아야 함.
2. **일반 관광 기초 미션의 입문·기본 레벨 전면 잠금** — 4차에서 사용자 확인 후 설계 유지로 확정, 더 이상 열린 과제 아님.
3. **실사용자 검증 필요**: 긴급 버튼 실제 발견률, TTS 재생 안정성(특히 중장년), 새로 추가된 "우선 학습 카테고리"·"어휘 주제 계속 학습하기" 안내의 실제 발견성.

## 결론
이번 라운드는 사용자가 실제로 앱을 사용하며 발견한 구체적 지적사항(아이콘 혼동, 배너 버그, 화면 완성도, 콘텐츠 흥미도) 위주였다. 코드로 해결 가능한 7건 모두 조치했고, 이미지·음성처럼 별도 생성 도구가 필요한 부분은 실제 코드/자산을 조사해 근거 있는 인수인계 문서로 정리했다. 자동 검증(301개 테스트 등)과 신규 계정 기반 실제 조작으로 회귀 없음을 확인했다.
