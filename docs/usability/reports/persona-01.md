# 페르소나 1: 가나도 모르는 첫 일본 여행자

> 합성 페르소나 테스트 결과. 실제 사용자 데이터가 아님.

## 1. 페르소나 요약
히라가나·가타카나를 전혀 모르는 완전 초보자. 첫 일본 여행을 앞두고 있음.

## 2. 테스트 환경
- `[코드 확인]` 로컬 dev 서버(`npm run dev`, http://localhost:5173), Chromium 기반 내장 브라우저.
- localStorage/IndexedDB 미러를 완전히 초기화한 **신규 사용자 상태**에서 시작 (`yangmung-mirror` IndexedDB까지 삭제해야 실제로 초기화됨 — 아래 문제 참조).

## 3. 수행한 과업
1. 완전 초보자 과정 찾기
2. 한글 발음 보조 활성화 여부 확인
3. 편의점 봉투 요청 표현 학습
4. 식당 주문 표현 학습
5. 호텔 체크인 표현 학습
6. 다음 날 복습 과정 확인

## 4. 완료한 과업
- **완전 초보자 과정 찾기**: `[실행 확인]` 온보딩 → 1분 수준진단 → "설레는 첫 여행자"(0/16 정답) → 추천 난이도 "입문"으로 정확히 진입. 홈 화면에 "히라가나 → 가타카나 → 기본 인사" 순서의 잠금 단계가 명확히 제시됨.
- **한글 발음 보조 확인**: `[실행 확인]` 입문 모드는 기본값이 "발음 보조 항상, 일본어+한글 보기"로 자동 설정됨(진단 결과 설명 문구). 히라가나 학습 카드에서 실제로 한글 발음("한글 소리 「아」")과 로마자가 함께 표시됨을 확인.

## 5. 실패하거나 중단된 과업
- **편의점/식당/호텔 표현 학습**: `[실행+코드 확인]` **실패**. 입문(및 기본) 레벨에서는 미션 탭 자체가 잠겨 있고("미션은 중급부터 열려요"), 편의점(C1)·식당(C2)·호텔(C10) 같은 여행 미션은 가나 트랙 전체를 통과해 "중급"으로 승급해야만 노출된다. 승급 후에도 특정 미션을 지정해서 열 수 없고(F3, 아래), 53개 장면 중 1개만 무작위로 열려 시작한다. 완전 초보자가 "오늘 편의점 표현만 배우고 싶다"는 목표를 최단 경로로 달성할 방법이 없다.
- **다음 날 복습 과정 확인**: `[코드 확인]` 복습 로직(약점 우선 재출제, cooldown) 자체는 존재하나, 이번 세션에서 아직 아무 것도 "학습 완료" 처리되지 않아 복습장이 비어 있어 실제 복습 사이클을 끝까지 관찰하지는 못함(`[실사용자 검증 필요]`: 실제 하루 텀을 두고 재방문했을 때 복습 추천이 체감상 적절한지).

## 6. 발견한 문제

### 문제 1: 초기화가 안 되는 로컬 저장소 (사소하지만 테스트 방법론에 영향)
- **페르소나**: 1 (테스트 진행 자체에 영향, 실제 사용자에게는 반대로 안전장치)
- **발생 위치**: 앱 부팅 시점 전역 (`src/learn/idbMirror.ts`)
- **증거 유형**: `[코드 확인]` + `[실행 확인]`
- **실제로 발생한 일**: `localStorage`만 지우고 새로고침하면 IndexedDB 미러(`yangmung-mirror`)가 자동으로 이전 상태를 복원한다. 두 저장소를 모두 지워야 진짜 "신규 사용자" 상태가 된다.
- **문제가 되는 이유**: 사용자 입장에서는 오히려 "브라우저가 데이터를 지워도 학습 기록이 안전하다"는 긍정적 기능이다. 다만 QA/테스트 관점에서는 문서화되지 않으면 "신규 사용자 재현"에 혼동을 준다.
- **심각도**: S4 경미 (사용자 영향 없음, 오히려 보호 기능)
- **개선 방향**: 해당 없음(의도된 안전장치). 다만 QA 문서에 "신규 사용자 재현 방법 = localStorage + IndexedDB(yangmung-mirror) 모두 삭제"를 남겨두면 좋음.

### 문제 2: 완전 초보자가 여행 회화(미션)에 도달하는 경로가 사실상 없음
- **페르소나**: 1 (5, 6, 7에도 동일 구조로 영향)
- **발생 위치**: 홈 화면 "여행 미션" 섹션, `학습` 탭 레벨 진도, `src/views/Map.tsx:48-73`
- **수행하려던 과업**: 편의점 봉투 요청 표현 학습
- **증거 유형**: `[실행 확인]` + `[코드 확인]`
- **실제로 발생한 일**: 입문 레벨 홈 화면에 "미션은 중급부터 열려요 — 지금은 가나·기본 단어를 다지는 단계예요. 레벨 진도를 다 통과하고 중급으로 승급하면 열려요"라는 안내만 표시된다. 코드상 `missionsLocked = coreLevel === 'beginner' || coreLevel === 'default'`로, 히라가나·가타카나·기본 인사 3단계와 쓰기 시험을 모두 마쳐야 승급 시험 응시 자격이 생기고, 그 후에도 승급 시험(20문항 90% 이상)을 통과해야 미션 탭이 열린다.
- **사용자가 기대할 행동**: 앱 설명("일본 여행에서 얼어붙지 않게")대로, 오늘 당장 편의점에서 쓸 문장 한두 개라도 먼저 맛보고 싶어 함.
- **문제가 되는 이유**: 완전 초보자가 첫 세션에서 "여행 회화"에 전혀 닿지 못하고 오직 가나 드릴만 반복하게 되어, 앱의 핵심 가치제안("여행 미션")을 체감하기까지 진입장벽이 매우 길다. 가나 3단계 + 기본인사 + 쓰기시험 + 승급시험을 모두 통과해야 하므로 실질적으로 여러 세션이 필요하다.
- **재현 단계**: 신규 상태 → 수준진단에서 전부 "모르겠어요" 패스 → "입문" 시작 → 홈/미션 탭 확인.
- **심각도**: S1 심각 (핵심 가치 체감을 첫 세션에 거의 완전히 차단)
- **발생 가능성**: 높음 (입문으로 분류되는 모든 사용자에게 동일하게 발생)
- **영향받는 다른 페르소나**: 5(안전 최우선 가족여행자, 응급 미션 접근 불가), 6(한달살기), 7(중장년)
- **개선 방향**: (제안만, 수정 금지 단계) 입문 레벨에서도 "맛보기 미션 1개"를 가나 학습과 병행 노출하는 방안 검토.
- **실제 사용자 검증 필요 여부**: 예 — "미션이 안 보이면 이탈하는가, 아니면 가나 학습에 몰입하는가"는 실사용자 반응을 봐야 함.

### 문제 3: 수준진단 '상황회화' 문항이 완전 초보자에게 사실상 풀 수 없는 형태
- **페르소나**: 1
- **발생 위치**: 수준진단 12~16/16번 문항 (`src/learn/placementCards.ts`, `src/views/Placement.tsx`)
- **수행하려던 과업**: 수준 진단 받기
- **증거 유형**: `[실행 확인]`
- **실제로 발생한 일**: 상황회화 5문항은 지문("ごちゅうもんは、おきまりですか？")과 4개 선택지(예: "メニューを、みせてください")가 모두 일본어 텍스트로만 제공된다. 한글 번역이 전혀 없어 가나를 모르는 사용자는 글자 모양조차 구분할 수 없다.
- **사용자가 기대할 행동**: 최소한 상황 설명(무슨 상황인지)이라도 한글로 주어져 "감으로" 답을 고를 여지가 있을 것으로 기대. (실제로는 상황 설명 자체는 한글로 제공됨 — "자리에 앉자 점원이 주문을 받으러 온다" — 그러나 선택지 4개는 여전히 일본어만.)
- **문제가 되는 이유**: 이 축(situation)의 점수는 읽기 실력이 0인 사용자에게 항상 낮게 나올 수밖에 없는 구조다. "모르겠어요" 패스가 있어 진행은 막히지 않지만(S0 아님), 완전 초보자에게 "나는 아무것도 모른다"는 좌절감을 반복해서 준다.
- **재현 단계**: 온보딩 → 수준진단 시작 → 12번 문항까지 진행.
- **심각도**: S2 중요
- **발생 가능성**: 높음 (완전 초보자 전원에게 동일 발생)
- **영향받는 다른 페르소나**: 없음(오히려 3, 4는 이 구간에서 실력을 보여줄 수 있어 유리)
- **개선 방향**: 상황회화 축은 선택지에 한글 뜻을 소괄호로 병기하거나, 읽기 축 점수가 매우 낮을 때는 이 축 문항 수를 줄이는 방안 검토.
- **실제 사용자 검증 필요 여부**: 예 — 패스가 반복될 때 사용자가 느끼는 좌절감의 정도.

### 문제 4: 첫 세션 종료 후 재방문 흐름 미검증
- **페르소나**: 1
- **증거 유형**: `[실사용자 검증 필요]`
- **실제로 발생한 일**: 확인하지 못함 — 시간 경과 시뮬레이션(예: localStorage 날짜 조작)까지는 수행하지 않음.
- **실제 사용자 검증 필요 여부**: 예 — 24시간 후 재방문 시 "오늘의 코치" 문구와 복습 추천이 실제로 체감상 도움이 되는지.

## 7. 학습 콘텐츠 적합성
- 히라가나 학습 카드는 `[실행 확인]` 한글 발음 대응, 비슷한 글자 경고(お↔あ), 기억법 니모닉, 3단계 한국어 획순 설명, 따라쓰기 캔버스까지 갖춰 완전 초보자에게 상당히 촘촘하게 설계되어 있음. 이 부분은 강점.
- 다만 F2에서 보듯, 그 촘촘한 가나 학습이 "여행 회화"라는 앱의 핵심 약속과 첫 세션 안에서 연결되지 않음.

## 8. 화면 및 조작 적합성
- `[실행 확인]` 온보딩 모달은 2개 버튼(진단 시작/건너뛰기)만으로 매우 단순. 회원가입 없음. 첫 학습까지 클릭 수가 적음(진단 16문항이 다소 길게 느껴질 수 있으나 "1분"으로 명시).
- `[실행 확인]` 오답/패스 시 정답을 즉시 보여주는 피드백은 명확함.

## 9. 여행 현장 활용 가능성
- `[코드+실행 확인]` 입문 단계에서는 여행 미션 자체가 잠겨 있어, 이 페르소나가 여행 당일까지도 미션을 열지 못했다면 여행 현장에서 앱이 제공하는 문장이 전무할 위험이 있음 (F2, F3와 직결).

## 10. 실제 사용자에게 검증해야 할 가설
- 미션이 보이지 않는 입문 단계에서 실제 초보자가 이탈하지 않고 가나 학습을 끝까지 지속하는지.
- 상황회화 문항 전량 패스가 반복될 때 느끼는 좌절감의 크기.
- 24시간 뒤 복습 유도 문구의 실제 재방문 전환율.

## 12. 이 페르소나에게 앱을 추천할 수 있는가
**조건부 가능.** 가나 학습 설계는 우수하나, "여행 회화를 빨리 써먹고 싶다"는 이 페르소나의 핵심 동기가 미션 잠금 구조(F2/F3) 때문에 여러 세션이 지나야 충족된다. 가나 학습에 인내심이 있는 사용자에게는 적합하지만, "당장 다음 주 여행" 같은 시급성이 있는 초보자에게는 현재 구조상 권하기 어렵다.
