# 페르소나 8: JLPT 시험 준비생

> 합성 페르소나 테스트 결과. 실제 사용자 데이터가 아님.
> **평가 기준**: 이 페르소나를 만족시킬 기능을 제안하는 것이 아니라, 앱이 "여행 실전 회화 앱"이라는 포지셔닝을 명확히 전달해 이 사용자가 빠르게 이탈/판단할 수 있게 하는지를 본다.

## 1. 페르소나 요약
JLPT(일본어능력시험) 대비를 목적으로 문법·한자·독해 학습을 찾는 사용자.

## 2. 테스트 환경
- `[실행 확인]` 온보딩 첫 화면 문구, 상단 네비게이션 탭 구성을 직접 확인.
- `[코드 확인]` `src/content/grammar.ts`, `src/content/n5.ts`, `src/content/verbForms.ts` 직접 리딩.

## 3. 수행한 과업
1. 앱 소개와 첫 화면 확인
2. 문법·한자·독해 과정 탐색
3. 앱이 자신의 목적에 맞는지 판단

## 4. 완료한 과업
- **앱 소개 확인 및 목적 판단**: `[실행 확인]` 온보딩 모달 첫 줄이 "여행 일본어에 오신 걸 환영해요 / 일본 여행에서 바로 쓰는 표현을 짧은 세션으로 익히는 앱이에요"로, **첫 화면에서 즉시 "이 앱은 여행 회화 전용"임을 알 수 있음.** 이 페르소나는 온보딩 모달 한 번만 보고도 "내 목적(시험 대비)과 다르다"를 빠르게 판단할 수 있는 근거가 충분함. **평가 기준상 이 부분은 긍정적.**
- **문법 과정 탐색**: `[코드 확인]` "문법"이라는 카테고리 자체는 문화·여행팁 라이브러리(`grammar.ts`) 안에 37개 존재하나, 체계적 커리큘럼이 아니라 "~ますか", "~ください" 같은 **미니 팁 카드**(예문 1개 + 흔한 실수 1개 + 실전 팁 1개, 일부는 JLPT N5 태그 병기)로 구성되어 있음. 시험 대비용 문형 정리표나 연습문제 형식이 아님.

## 5. 실패하거나 중단된 과업
- **한자 학습 탐색**: `[코드 확인]` 한자 전용 학습 화면은 존재하지 않는다. `choiceMode: 'kanji'`는 퀴즈 선택지 표기를 한자로 바꾸는 표시 옵션일 뿐, 한자 자체를 가르치는 커리큘럼이 아니다. **실패.**
- **독해 과정 탐색**: `[코드 확인]` 지문 독해 훈련용 화면(장문 읽기·문제풀이)은 확인되지 않음. **실패.**
- **JLPT N5 커버리지 확인**: `[코드 확인]` `src/content/n5.ts`는 `source: 'unofficial'`로 명시된 **내부 검증용 데이터**이며(`npm run report:n5`로만 조회), 사용자에게 "JLPT N5 대비 화면"으로 노출되지 않는다. 즉 겉으로는 JLPT 관련 학습 화면이 전혀 보이지 않음(내부적으로만 태깅되어 품질관리에 쓰임). **실패**(애초에 사용자 대상 기능이 아니므로 당연한 결과).

## 6. 발견한 문제

### 문제 1 (참고용, 심각도 낮음): 미션 세션 중 "JLPT N5 참고" 라벨이 우연히 노출되어 혼동 소지
- **페르소나**: 8
- **발생 위치**: 미션 세션 중 문법 카드 하단 (`persona-04 테스트에서 실행 확인: "~ますか" 카드에 "JLPT N5 참고: n5_g_masu" 텍스트 노출`)
- **수행하려던 과업**: (직접 과업은 아니나 교차 확인 중 발견)
- **증거 유형**: `[실행 확인]`
- **실제로 발생한 일**: 여행 미션(공항 입국심사) 진행 중 삽입된 문법 미니팁 카드 하단에 "JLPT N5 참고: n5_g_masu" 같은 내부 식별자 형태의 문구가 그대로 노출됨.
- **사용자가 기대할 행동**: 일반 여행 회화 학습자에게는 불필요한 정보이며, 반대로 JLPT 준비생이 우연히 이 문구를 보면 "이 앱에 JLPT 콘텐츠가 있나?"라고 오해해 시간을 들여 탐색했다가 실망할 수 있음.
- **문제가 되는 이유**: 두 방향 모두에 약간의 노이즈. 일반 사용자에게는 낯선 전문용어 노출, JLPT 준비생에게는 헛된 기대 유발.
- **재현 단계**: 중급 모드 진입 → 아무 미션이나 시작 → 문법 카드(예: ~ますか) 확인.
- **심각도**: S4 경미
- **발생 가능성**: 높음 (문법 카드가 있는 모든 세션)
- **영향받는 다른 페르소나**: 1, 4 등 일반 학습자에게도 미미하게 해당
- **개선 방향**: 내부 식별자(`n5_g_masu`)는 사용자 화면에서 숨기거나 "JLPT N5 수준" 같은 자연어로 순화 검토.
- **실제 사용자 검증 필요 여부**: 예 — 실제로 이 문구를 본 JLPT 준비생이 어떤 반응을 보이는지.

## 7. 학습 콘텐츠 적합성
- `[코드 확인]` 이 페르소나의 목적(시험 대비) 기준으로는 콘텐츠가 전혀 적합하지 않음 — 그러나 이는 문제가 아니라 **의도된 포지셔닝**이다. 앱은 "여행 실전 회화"에 집중되어 있고, 문법 미니팁도 여행 중 바로 쓰는 문형(정중 의문, 요청 표현, 조사)에 한정되어 있어 방향성이 일관됨.

## 8. 화면 및 조작 적합성
- `[실행 확인]` 온보딩 문구만으로 목적 불일치를 즉시 인지할 수 있어 조작 자체에 오래 머무를 필요가 없음(빠른 이탈이 가능하다는 것 자체가 이 페르소나 기준으로는 "좋은 UX").

## 9. 여행 현장 활용 가능성
- 해당 없음(이 페르소나의 목적과 무관).

## 10. 실제 사용자에게 검증해야 할 가설
- 실제 JLPT 준비생이 앱스토어 설명·스크린샷만 보고도 온보딩 진입 전에 이미 걸러지는지(사전 필터링 효과), 아니면 설치 후 온보딩을 보고서야 이탈하는지.

## 12. 이 페르소나에게 앱을 추천할 수 있는가
**추천하지 않음 — 그리고 이것이 올바른 결과.** 이 앱은 JLPT 문법·한자·독해 준비용으로 설계되지 않았고, 온보딩 문구가 이를 첫 화면에서 정직하게 전달한다. 종합 분석 보고서에서 다루듯, 이 페르소나를 만족시키기 위해 문법/한자 기능을 추가하는 것은 앱의 핵심 포지셔닝(여행 실전 회화)을 흐리는 방향이므로 권장하지 않는다.
